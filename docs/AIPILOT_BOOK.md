## 서문

### 왜 이 책인가

현대 공중전 인공지능은 대개 설명할 수 없는 신경망으로 비행을 제어한다. 잘 날지만 왜 그렇게
움직이는지 설명할 수 없고, 불확실한 상황에서 평균적인 기동으로 뭉개진다. 이 책은 반대의 길을
택한다. 설명 가능하고, 결정론적이며, 교과서로 인용할 수 있는 방법만으로 F-16 자율 공중전
조종사(AIPILOT)를 처음부터 끝까지 구현한다.

구체적으로 우리는 다음을 한다.

첫째, 비행 제어를 게인 스케줄 LQR(선형 2차 조절기)과 INDI(증분 비선형 동적 역변환)로 구현하고
안정성을 수식으로 증명한다. 둘째, 전술 의사결정을 규칙과 오프라인 학습을 합친 투명한 정책으로
구현한다. 셋째, 이 모든 것을 오픈소스 JSBSim의 F-16 6자유도 시뮬레이터 위에서 재현 가능하게
돌린다. 넷째, 형식 검증(Z3)과 고받음각 실증(NASA TP-1538)으로 주장을 뒷받침한다.

즉 이 책은 인공지능이 비행기를 어떻게 모는가를 코드 한 줄까지 추적할 수 있는 형태로 가르친다.

### 대상 독자와 선수지식

주 독자는 학부 3, 4학년부터 대학원 입문 수준이다. 항공, 제어, 로보틱스, 인공지능 전공이거나 그
교차 분야를 공부하는 사람을 가정한다.

선수지식은 거의 요구하지 않는다. 미적분과 선형대수의 기초, 그리고 파이썬 코드를 읽을 수 있으면
충분하다. 벡터와 행렬, 미분방정식, 확률의 최소 개념은 필요한 곳에서 그때그때 정의한다.

별표를 붙인 절은 증명이나 고급 유도 등 심화 내용이다. 처음 읽을 때는 건너뛰어도 흐름이 끊기지
않는다.

### 이 책을 읽는 법

모든 장은 같은 형식을 따른다. 장 첫머리에 학습 목표를 두어 그 장을 마치면 무엇을 할 수 있게 되는지
밝힌다. 서술은 무엇을 정의하고, 왜 그렇게 했는지 동기를 말하고, 어떻게 하는지 절차를 보인 다음,
예시와 연습문제로 닫는다. 모든 용어는 처음 등장할 때 정의한다. 비유보다 목적과 설계를 먼저 말한다.
장 끝에는 연습문제와 필요한 용어집을 둔다.

집필 표준의 모범은 의사결정 정책 장(NEW_ENGINE_BT_POLICY_SPEC.md)이다. 이 깊이가 모든 장의
기준이다.

### 재현성 원칙

이 책의 모든 결과는 코드로 재현된다. 각 장은 실행 명령을 명시한다. 핵심 환경은 Python 3.14,
JSBSim 1.3.0, numpy와 scipy이며, 검증에는 z3-solver를 쓴다. 엔진 본체는 자급식이며 F-16 비행
데이터를 함께 담는다(new_match_engine/jsbsim_data, LGPL-2.1).

## 표기법

장 사이의 혼동을 막기 위해 기호와 단위, 부호를 여기서 한 번에 정한다. 본문은 이 규약을 따른다.
출처와 정합은 new_match_engine/TACTIC_SPEC.md 이다.

### 단위 (외부 인터페이스)

| 물리량 | 단위 | 비고 |
|---|---|---|
| 각도 | 도 | 라디안은 시뮬레이터 내부에서만, 경계에서 변환 |
| 방위(heading) | 도, 0에서 360, 진북 기준, 시계방향 증가 | 절대값 |
| 고도 | 피트, 해면 기준 | 절대값 |
| 속도 | 외부는 노트(CAS), 제어 내부는 피트퍼초(TAS) | 경계에서 변환 |
| 거리 | 피트 | |
| 시간 | 초 | tick 주기로 환산 |

### 상태와 기하 기호

| 기호 | 뜻 | 부호와 범위 |
|---|---|---|
| psi | 방위 | 0에서 360도 |
| theta | 피치 자세각 | 상승이 양수 |
| phi | 롤 뱅크각 | 우뱅크가 양수 |
| V | 속도 | 양수 |
| h | 고도 | 양수 |
| ATA | 내 기수에서 적까지의 각 | 0에서 180도, 0이 정조준 |
| AA | 적 꼬리 기준 내 각 | 0에서 180도 |
| HCA | 진행방향 사잇각 | 0에서 180도 |
| closure | 거리 변화율 | 접근이 양수, 이격이 음수, 노트 |
| Es | 비에너지, 고도 더하기 속도에너지 | 피트 등가 |
| rel_b | 상대방위 | 플러스마이너스 180도, 우측 양수 |

### 제어 입력과 목표값

| 기호 | 뜻 |
|---|---|
| u = (throttle, elevator, aileron, rudder) | 조종면 명령 |
| Setpoint = (psi*, h*, V*) | 유도가 만든 목표값 |
| K | LQR 게인 행렬, u = u0 빼기 K 곱하기 (x 빼기 x*) |
| g_bar | INDI 제어효과 |

### 속도(rate)

| 기호 | 뜻 | 단위 |
|---|---|---|
| p, q, r | 롤, 피치, 요 각속도 | 내부 라디안퍼초, 표시 도퍼초 |
| ego_r_dps, enm_r_dps | 나와 적의 요 각속도 | 도퍼초, 부호 있음 |

### 게임 규칙 상수

| 이름 | 값 |
|---|---|
| 무장 사용 구역 | ATA 12도 미만이고 거리 500에서 3000피트, 초당 최대 25 피해 |
| 최저고도(hard deck) | 1000피트 미만이면 패배 |
| 한 판 길이 | 300초 |
| tick 주기 | 물리 120Hz, 제어 20Hz, 의사결정 10Hz |

### 정밀도 규약

내부 계산은 배정밀도(float64)로 한다. 표시 자릿수는 물리량별로 통일한다(각도 1도, 거리 1피트,
점수 소수 둘째 자리 등). 분모에는 항상 0 나눗셈 방지 항을 더한다.
