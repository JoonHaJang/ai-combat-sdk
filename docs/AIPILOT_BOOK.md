# AIPILOT
### F-16 AI Pilot Implementation with JSBSim

Joonha Jang, 2026. All rights reserved.

---

이 파일은 책의 표지, 서문, 표기법, 그리고 장별 구성안(목차와 각 장의 내용 계획)이다. 각 장은
docs/book 폴더의 번호순 파일이며 여기서 링크한다. 참조용 자료는 docs/reference에 있다.

이 책의 서사는 두 부분이다. 먼저 1대1 dogfight가 무엇이고 어떻게 푸는지를 교범 수준으로 다룬다.
그다음 그 이론을 AIPILOT으로 구현하는 과정을 한 단계씩, 토대에서 통합까지 쌓아 올린다.

## 서문

### 왜 이 책인가

현대 공중전 인공지능은 대개 설명할 수 없는 신경망으로 비행을 제어한다. 잘 날지만 왜 그렇게
움직이는지 설명할 수 없고, 불확실한 상황에서 평균적인 기동으로 뭉개진다. 이 책은 반대의 길을
택한다. 설명 가능하고, 결정론적이며, 교과서로 인용할 수 있는 방법만으로 F-16 자율 공중전
조종사(AIPILOT)를 처음부터 끝까지 구현한다.

구체적으로 우리는 1대1 dogfight의 이론(BFM과 에너지 기동)을 정리하고, 비행 제어를 게인 스케줄
LQR과 INDI로 구현해 안정성을 수식으로 증명하며, 전술 의사결정을 규칙과 오프라인 학습을 합친
투명한 정책으로 구현하고, 이 모두를 오픈소스 JSBSim의 F-16 6자유도 시뮬레이터 위에서 재현
가능하게 돌린다. 그리고 형식 검증(Z3)과 고받음각 실증(NASA TP-1538)으로 주장을 뒷받침한다.

### 대상 독자와 선수지식

주 독자는 학부 3, 4학년부터 대학원 입문 수준이다. 항공, 제어, 로보틱스, 인공지능 또는 그 교차
분야를 공부하는 사람을 가정한다. 선수지식은 거의 요구하지 않는다. 미적분과 선형대수의 기초,
파이썬 코드를 읽을 수 있으면 충분하다. 벡터와 행렬, 미분방정식, 확률의 최소 개념은 필요한 곳에서
그때그때 정의한다. 별표를 붙인 절은 증명이나 고급 유도 등 심화 내용으로, 처음 읽을 때는 건너뛰어도
흐름이 끊기지 않는다.

### 이 책을 읽는 법

모든 장은 같은 형식을 따른다. 장 첫머리에 학습 목표를 두고, 무엇을 정의하고 왜 그렇게 했는지
동기를 말하고 어떻게 하는지 절차를 보인 다음, 예시와 연습문제로 닫는다. 모든 용어는 처음 등장할
때 정의하고, 비유보다 목적과 설계를 먼저 말한다. 집필 표준의 모범은 의사결정 정책 장
(book/08_decision_policy.md)과 1대1 공중전 상황 장(book/03_bfm_situations.md)이다.

### 재현성 원칙

모든 결과는 코드로 재현된다. 각 장은 실행 명령을 명시한다. 핵심 환경은 Python 3.14, JSBSim 1.3.0,
numpy와 scipy이며, 검증에는 z3-solver를 쓴다. 엔진 본체는 자급식이며 F-16 비행 데이터를 함께
담는다(new_match_engine/jsbsim_data, LGPL-2.1).

## 표기법

장 사이 혼동을 막기 위해 기호와 단위, 부호를 여기서 한 번에 정한다. 출처와 정합은
new_match_engine/TACTIC_SPEC.md 이다.

### 단위 (외부 인터페이스)
| 물리량 | 단위 | 비고 |
|---|---|---|
| 각도 | 도 | 라디안은 시뮬레이터 내부에서만, 경계에서 변환 |
| 방위(heading) | 도, 0에서 360, 진북 기준, 시계방향 증가 | 절대값 |
| 고도 | 피트, 해면 기준 | 절대값 |
| 속도 | 외부는 노트(CAS), 제어 내부는 피트퍼초(TAS) | 경계에서 변환 |
| 거리 | 피트 | |
| 시간 | 초 | tick 주기로 환산 |

### 상태와 기하 기호
| 기호 | 뜻 | 부호와 범위 |
|---|---|---|
| psi | 방위 | 0에서 360도 |
| theta | 피치 자세각 | 상승이 양수 |
| phi | 롤 뱅크각 | 우뱅크가 양수 |
| V | 속도 | 양수 |
| h | 고도 | 양수 |
| ATA | 내 기수에서 적까지의 각 | 0에서 180도, 0이 정조준 |
| AA | 적 꼬리 기준 내 각 | 0에서 180도 |
| HCA | 진행방향 사잇각 | 0에서 180도 |
| closure | 거리 변화율 | 접근이 양수, 이격이 음수, 노트 |
| Es | 비에너지, 고도 더하기 속도에너지 | 피트 등가 |

### 제어 입력과 목표값
| 기호 | 뜻 |
|---|---|
| u = (throttle, elevator, aileron, rudder) | 조종면 명령 |
| Setpoint = (psi*, h*, V*) | 유도가 만든 목표값 |
| K | LQR 게인 행렬, u = u0 빼기 K 곱하기 (x 빼기 x*) |
| g_bar | INDI 제어효과 |

### 게임 규칙 상수
| 이름 | 값 |
|---|---|
| 무장 사용 구역 | ATA 12도 미만이고 거리 500에서 3000피트. 피해율(초당) = 25 곱하기 거리계수 곱하기 각도계수. 거리계수 = (3000 빼기 거리) 나누기 2500. 각도계수 = 1 빼기 ATA 나누기 12 |
| 최저고도(hard deck) | 1000피트 미만이면 패배 |
| 한 판 길이 | 300초 |
| tick 주기 | 물리 120Hz, 제어 20Hz, 의사결정 10Hz |

내부 계산은 배정밀도이며, 분모에는 항상 0 나눗셈 방지 항을 더한다.

## 책의 서사 구조

이 책은 다음 흐름으로 읽도록 설계되었다. 왼쪽이 이론, 오른쪽으로 갈수록 구현이다.

```
[1부] 문제와 이론        [2부] 토대            [3부] 제어         [4부] 유도        [5부] 의사결정       [6부] 통합·검증
왜 / 무엇 / 어떻게 푸나   시뮬레이터·기체        목표대로 날리기     전술을 목표로      전술을 고르기        합치고 증명하기
  dogfight 이론            JSBSim·F-16·선형화    LQR·cascade·INDI   pursuit·PN·요요    관측·정책·학습       엔진·bridge·검증
```

각 부는 "그 단계가 무엇이고, 왜 필요하며, 어떻게 구현하고, 무엇으로 검증했는가"를 답한다.

- 그림(추가 예정): 추격 곡선 3종, one/two-circle 흐름, 통제 구역, 3-9선 오버슈트.

장 5. 동역학의 선형화 — 비선형을 운영점에서 직선으로. 파일 신규 book/05_linearization.md
