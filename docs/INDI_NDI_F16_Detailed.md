## 1. 연구 개요

### 1.1 연구 배경

F-16 Fighting Falcon은 **완화 정적 안정성(relaxed static stability)**을 갖춘 고기동 전투기입니다. 이 설계 철학은 기체의 기동성을 극대화하지만, 그 대가로 **본질적으로 불안정(inherently unstable)**한 동역학 특성을 가집니다. 따라서 F-16은 지속적인 능동적 안정화(active stabilization) 없이는 지속 비행이 불가능합니다. 이로 인해 Fly-by-Wire(FBW) 시스템과 고성능 비선형 제어기법의 도입이 필수적입니다.

기존의 PID(Proportional-Integral-Derivative) 제어기는 정상 운전점 근처에서는 양호한 성능을 보이나, F-16의 비선형, 축간 결합, 외란에 취약한 특성을 고려할 때 고기동 영역에서는 성능이 급격히 저하됩니다.

### 1.2 연구 목적

본 연구는 F-16 전투기의 자세(pitch/roll) 제어에 대해 다음 두 가지 비선형 제어 기법을 비교합니다:

- **NDI (Nonlinear Dynamic Inversion)**: 전체 비선형 동역학을 정확히 알고 이를 역전시켜 선형화하는 모델 기반 접근
- **INDI (Incremental Nonlinear Dynamic Inversion)**: 전체 모델 대신 **센서 기반 증분(incremental)** 관계를 역전시키는 강건성 중심 접근

연구의 핵심 목표는 **모델 불확실성, 센서 노이즈, 액추에이터 포화, 외란** 등 비현실적 조건에서 INDI가 NDI 대비 강건성 우위를 보이는지를 정량적으로 검증하는 것입니다.

### 1.3 기여

- 6-DoF 비선형 F-16 모델을 MATLAB/Simulink에 구축
- PID -> NDI -> INDI의 계층적 제어 구조 설계
- 정상 조건 및 모델 불확실성 조건에서의 RMSE, ISE, 평균 오차, 지연 시간 기반 정량 비교
- INDI의 센서 기반 적응성이 NDI의 모델 의존성보다 실제 환경에서 유리함을 실증

## 2. F-16 수학적 모델링

본 장은 F-16 전투기의 6-DoF 비선형 동역학 모델을 체계적으로 유도합니다. 모델은 Etkin & Reid [17], Cook [18], Stevens & Lewis [19], Nelson [20], Beard & McLain [21] 등의 고전 항공 역학을 참고하여 구축되었습니다.

### 2.1 좌표계 및 참조 프레임

항공기 운동을 정밀히 기술하기 위해 4가지 좌표계를 정의합니다.

#### 2.1.1 관성계 (Inertial Frame)

- 지구 표면 또는 지구 중심(ECI)을 원점으로 하는 비가속 좌표계
- 일반적으로 **NED(North-East-Down)** 또는 **ENU(East-North-Up)** 규칙 사용
- 위치, 속도, 가속도를 기술하는 기준 프레임
- 지구 곡률과 자전은 저고도/저속 비행에서 무시 가능 (평평한 지구 가정)
- 위치 벡터: **p_I = [x, y, z]^T**

#### 2.1.2 기체고정계 (Body-Fixed Frame)

- 기체 CG를 원점으로 하며 기체와 함께 회전
- 축 정의:
  - **x_b**: 기종 방향 (전방 양)
  - **y_b**: 우측 날개 방향
  - **z_b**: 하방 (오른손 좌표계)
- 힘, 모멘트, 속도, 각속도는 모두 이 프레임에서 표현

#### 2.1.3 풍좌표계 (Wind Frame)

- 상대 기류 방향을 기준으로 정렬
- 축 정의:
  - **x_w**: 속도 벡터 방향 (대기속도 방향)
  - **z_w**: 기체 수직면 내 하방
  - **y_w**: 오른손 좌표계 완성 (우측)
- **어택 각(Angle of Attack, alpha)**: 기체 x_b 축과 풍 x_w 축 사이의 각도 (수직면 내)
- **사이드슬립 각(Sideslip Angle, beta)**: 기체 x_b 축과 풍 x_w 축 사이의 각도 (수평면 내)

#### 2.1.4 안정좌표계 (Stability Frame)

- 풍좌표계의 특수한 경우로, beta = 0을 가정
- x 축은 기체 대칭면에 투영된 속도 벡터 방향
- 주로 종방향(longitudinal) 동역학 단순화에 사용 (피치율 q, 어택 각 alpha, elevator 입력 등)

### 2.2 좌표 변환 및 오일러 각

#### 2.2.1 회전 행렬의 유도

항공기의 자세는 **오일러 각(Euler angles)** (phi, theta, psi)로 표현됩니다. 관성계에서 기체고정계로의 변환은 세 번의 연속적인 회전으로 이루어집니다:

1. **요(Yaw) 회전**: 관성 z 축 주위로 psi만큼 회전 -> R_z(psi)
2. **피치(Pitch) 회전**: 중간 y 축 주위로 theta만큼 회전 -> R_y(theta)
3. **롤(Roll) 회전**: 최종 x 축 주위로 phi만큼 회전 -> R_x(phi)

각 기본 회전 행렬:

```
R_x(phi) = | 1      0           0       |
           | 0   cos(phi)   sin(phi)    |
           | 0  -sin(phi)   cos(phi)    |

R_y(theta) = | cos(theta)   0   -sin(theta) |
             |     0        1       0      |
             | sin(theta)   0    cos(theta) |

R_z(psi) = | cos(psi)   sin(psi)   0 |
            | -sin(psi)  cos(psi)   0 |
            |    0          0      1 |
```

**완전한 변환 행렬** (관성 -> 기체):

```
R_b/n = R_x(phi) * R_y(theta) * R_z(psi)

R_b/n = | c_t*c_p      c_t*s_p     -s_t     |
        | s_f*s_t*c_p - c_f*s_p   s_f*s_t*s_p + c_f*c_p   s_f*c_t |
        | c_f*s_t*c_p + s_f*s_p   c_f*s_t*s_p - s_f*c_p   c_f*c_t |
```
(단, c_() = cos(), s_() = sin())

#### 2.2.2 기체 -> 풍 변환 행렬

어택 각 alpha와 사이드슬립 각 beta를 이용한 기체축에서 풍축으로의 변환:

```
T_bw = | cos(a)*cos(b)   sin(b)    sin(a)*cos(b) |
       | -cos(a)*sin(b)  cos(b)   -sin(a)*sin(b) |
       | -sin(a)           0        cos(a)      |
```

**정당성**: 먼저 z_b 축 주위로 beta 회전(요 방향 정렬), 그 후 y_b 축 주위로 alpha 회전(피치 방향 정렬). 두 회전의 합성으로 위 행렬이 도출됩니다.

#### 2.2.3 기체 -> 안정 변환 행렬 (beta = 0)

사이드슬립이 없을 때(beta = 0), 풍좌표계는 안정좌표계와 동일하며 변환은 단순화됩니다:

```
T_bs = | cos(a)   0   sin(a) |
       |    0     1     0    |
       | -sin(a)  0   cos(a) |
```

이는 y_b 축(측면 축) 주위로 alpha만큼 회전한 결과입니다.

#### 2.2.4 짐벌락(Gimbal Lock) 문제

오일러 각은 theta = +/- 90도에서 **짐벌락** 현상이 발생합니다. 이는 두 회전 축이 정렬되어 자유도가 하나 상실되는 특이점입니다. 실제 항공 시뮬레이션에서는 이를 피하기 위해 **쿼터니언(quaternion)** 표현이 자주 사용됩니다.

### 2.3 강체 운동학 (Kinematics)

#### 2.3.1 평행 운동학 (Translational Kinematics)

관성계에서의 위치 벡터: **p_I = [x, y, z]^T**

위치의 시간 변화율은 관성계 속도 벡터와 같습니다. 관성계 속도는 기체축 속도를 관성계로 변환하여 얻습니다:

```
dot(p_I) = T_BI * v_b = T_BI * [u, v, w]^T
```

- u, v, w: 기체축 선속도 (전방, 측방, 하방)
- T_BI: 기체 -> 관성 변환 행렬 (R_b/n과 동일)

**정당성**: 기체축 속도 벡터를 관성계 방향으로 투영하기 위해 기체 -> 관성 변환 행렬을 곱합니다.

#### 2.3.2 회전 운동학 (Rotational Kinematics)

기체축 각속도: **omega_b = [p, q, r]^T**

오일러 각의 시간 변화율은 기체축 각속도와 비선형적으로 연결됩니다:

```
| dot(phi)   |   | 1   sin(phi)*tan(theta)   cos(phi)*tan(theta)  |   | p |
| dot(theta) | = | 0      cos(phi)            -sin(phi)           | * | q |
| dot(psi)   |   | 0   sin(phi)/cos(theta)   cos(phi)/cos(theta)  |   | r |
```

**정당성**: 오일러 각의 시간 미분은 기체축 각속도를 오일러 각 변화율로 변환하는 행렬을 통해 얻어집니다. 이 행렬은 연속적인 3축 회전의 합성으로부터 유도됩니다. theta = +/- 90도에서 tan(theta)와 1/cos(theta)가 특이점이 되는 것이 짐벌락의 원인입니다.

#### 2.3.3 외적(Skew-Symmetric) 행렬

각속도 벡터의 외적을 행렬 형태로:

```
omega_b x v = [omega_b]_x * v

[omega_b]_x = |  0   -r    q  |
              |  r    0   -p  |
              | -q    p    0  |
```

이 행렬은 **회전 좌표계에서 발생하는 가상(Coriolis, Euler) 가속**을 계산하는 데 필수적입니다.

#### 2.3.4 공기역학 각도

기체축 속도 성분 u, v, w로부터 공기역학 각도를 계산:

**총 대기속도(Total Airspeed)**: V = sqrt(u^2 + v^2 + w^2)

**어택 각(Angle of Attack)**: alpha = atan(w / u)

**정당성**: u와 w는 기체의 종방향(x-z 평면) 속도 성분입니다. 이들의 비율은 기체 축선과 상대 기류 사이의 수직면 각도를 정확히 나타냅니다.

**사이드슬립 각(Sideslip Angle)**: beta = arcsin(v / V)

**정당성**: 측방 속도 v를 총 속도 V로 나눈 값은 기체 축선과 상대 기류 사이의 수평면 편차 각도의 사인을 나타냅니다.

### 2.4 운동 방정식 (Equations of Motion)

#### 2.4.1 평행 운동 (Newton 제2법칙)

기체축에서의 Newton 제2법칙은 회전 좌표계의 가상 가속을 포함합니다:

```
F_b = m * (dot(v_b) + omega_b x v_b)
```

성분 형태로 전개:

- X = m * (dot(u) + q*w - r*v)
- Y = m * (dot(v) + r*u - p*w)
- Z = m * (dot(w) + p*v - q*u)

**정당성**: 기체축은 비관성계이므로, 상대 가속(dot(v_b)) 외에 Coriolis 항(omega_b x v_b)이 추가됩니다. 이는 회전하는 좌표계에서 물리 법칙을 적용할 때의 필수적 수정입니다.

- X, Y, Z: 기체축 외력 (공기역학 + 추진 + 중력)
- p, q, r: 기체축 각속도
- m: 항공기 질량

#### 2.4.2 회전 운동 (Euler 법칙)

강체의 회전 운동은 각운동량의 시간 변화율로 기술됩니다:

```
M_b = I * dot(omega_b) + omega_b x (I * omega_b)
```

**정당성**: 이는 회전하는 좌표계에서 각운동량 정리를 적용한 결과입니다. 첫 번째 항은 관성좌표계에서의 각가속도에 의한 모멘트 변화, 두 번째 항은 회전 좌표계에서의 기여(Gyroscopic couple)입니다.

관성 행렬:

```
I = | I_xx   -I_xy   -I_xz |
    | -I_xy   I_yy   -I_yz |
    | -I_xz  -I_yz    I_zz |
```

F-16의 경우 x-z 평면 대칭을 가정하여 I_xy = I_yz = 0로 단순화하지만, I_xz != 0을 허용합니다. 이로 인해 롤-요 결합이 발생합니다.

성분 형태로 전개:

- L = I_xx * dot(p) - I_xz * dot(r) + (I_zz - I_yy) * q*r - I_xz * p*q
- M = I_yy * dot(q) + (I_xx - I_zz) * p*r + I_xz * (p^2 - r^2)
- N = I_zz * dot(r) - I_xz * dot(p) + (I_yy - I_xx) * p*q + I_xz * q*r

**정당성**: 관성 행렬을 성분별로 전개하고 외적 항을展開하면 위 식들이 도출됩니다. I_xz 항은 롤과 요 사이의 동역학적 결합(coupling)을 나타내며, 이는 전투기의 비대칭 형상으로 인해 발생합니다.

- L, M, N: 기체축 외부 모멘트 (공기역학 + 추진)
- I_xx, I_yy, I_zz: 축 관성 모멘트

#### 2.4.3 총 힘 및 모멘트

항공기에 작용하는 힘과 모멘트는 세 가지 주요 출처에서 비롯됩니다:

1. **공기력 및 공기역학 모멘트**: 기체 표면의 압력 및 전단 분포로 인한 힘과 모멘트
2. **추진력**: 엔진/모터 시스템이 생성하는 힘 (주로 종방향)
3. **중력**: 지구 중심 방향으로 작용하는 질량 힘

중력 벡터는 관성계에서 F_g = [0, 0, mg]^T로 표현되며, 기체축으로 변환:

```
F_g^B = R_IB * [0, 0, mg]^T
```

R_IB를 오일러 각으로 전개하고, psi의 영향이 작다고 가정하면:

```
F_g^B = mg * [-sin(theta), sin(phi)*cos(theta), cos(phi)*cos(theta)]^T
```

**정당성**: 중력은 항상 수직 하방으로 작용합니다. 기체가 피치(theta)와 롤(phi) 각도로 기울어져 있으면, 중력의 기체축 성분은 위와 같이 삼각함수로 표현됩니다. psi(요) 각은 수직 축 회전이므로 중력의 방향에는 영향을 주지 않습니다.

### 2.5 공기력 및 공기역학 모멘트

#### 2.5.1 공기력의 기본 정의

풍축 공기력은 세 직교 성분으로 분해됩니다:

- **양력(Lift, L)**: 상대 기류에 수직 (위쪽)
- **항력(Drag, D)**: 상대 기류에 평행 (반대 방향)
- **측력(Side Force, Y)**: 측방으로 작용

비차원 계수를 이용하여:

- L = 1/2 * rho * V^2 * S * C_L
- D = 1/2 * rho * V^2 * S * C_D
- Y = 1/2 * rho * V^2 * S * C_Y

- rho: 공기 밀도
- V: 대기속도
- S: 날개 면적 (기준 면적)

**정당성**: 동압(q = 1/2 * rho * V^2)과 기준 면적(S)의 곱은 특성 힘의 차원을 제공하며, 비차원 계수 C_L, C_D, C_Y는 항공기 형상과 유동 조건만에 의해 결정됩니다.

#### 2.5.2 풍축 -> 기체축 변환

풍축에서 기체축으로의 변환:

- C_X = -C_D * cos(alpha) + C_L * sin(alpha)
- C_Z = -C_D * sin(alpha) - C_L * cos(alpha)

**정당성**: 풍좌표계에서 기체축으로의 변환은 alpha 회전에 해당합니다. 항력 D는 풍 x_w 축의 반대 방향이므로 기체 x_b 축 성분은 -D*cos(alpha)이고, 양력 L은 풍 z_w 축의 반대 방향이므로 기체 x_b 축 성분은 +L*sin(alpha)입니다. Z 방향 성분도 동일한 논리로 유도됩니다.

#### 2.5.3 공기역학 모멘트

기체축 모멘트 계수:

- L = 1/2 * rho * V^2 * S * b * C_l
- M = 1/2 * rho * V^2 * S * c_bar * C_m
- N = 1/2 * rho * V^2 * S * b * C_n

- b: 윙스팬
- c_bar: 평균 공기역학 코드(MAC)
- C_l, C_m, C_n: 롤, 피치, 요 모멘트 계수

#### 2.5.4 F-16 공기역학 계수 모델

F-16의 공기역학 계수는 비선형 룩업 테이블(lookup table)로 표현되며, alpha, beta, 각속도, 제어 표면 편각의 함수입니다. 논문에서 사용된 선형화된 기본 형태는 다음과 같습니다:

**양력 계수**:

```
C_L = C_L0 + C_Lalpha * alpha + C_Lq * (q*c_bar)/(2*V) + C_Lde * delta_e
```

**항력 계수**:

```
C_D = C_D0 + C_Dalpha * alpha + C_Dalpha2 * alpha^2 + C_Dde * delta_e
```

**측력 계수**:

```
C_Y = C_Ybeta * beta + C_Yp * (p*b)/(2*V) + C_Yr * (r*b)/(2*V) + C_Ydr * delta_r
```

**롤 모멘트 계수**:

```
C_l = C_lbeta * beta + C_lp * (p*b)/(2*V) + C_lr * (r*b)/(2*V) + C_lda * delta_a + C_ldr * delta_r
```

**피치 모멘트 계수**:

```
C_m = C_m0 + C_malpha * alpha + C_mq * (q*c_bar)/(2*V) + C_mde * delta_e
```

**요 모멘트 계수**:

```
C_n = C_nbeta * beta + C_np * (p*b)/(2*V) + C_nr * (r*b)/(2*V) + C_nda * delta_a + C_ndr * delta_r
```

**정당성**: 각 계수는 정상 상태(trim) 조건 주변에서 테일러 전개(Taylor expansion)의 1차 항으로 근사됩니다. 예를 들어, 피치 모멘트는 어택 각 alpha에 거의 선형적으로 의존하고, 각속도(q)와 제어 입력(delta_e)은 추가 항으로 포함됩니다. 비선형 항(alpha^2 등)은 고어택 각 영역에서 필수적입니다.

### 2.6 추진 및 엔진 모델링

F-16은 단발 애프터버닝 터보팬 엔진을 탑재하여 높은 추력-대-중량비를 제공합니다.

#### 2.6.1 스로틀 명령 -> 추력

스로틀 레버 위치 delta_t와 명령 추력 P_c의 관계:

```
P_c(delta_t) = 64.94 * delta_t           (if delta_t <= 77)
P_c(delta_t) = 217.38 * delta_t - 117.38 (if delta_t > 77)
```

**정당성**: 스로틀 77% 지점에서 기울기가 급변하는 것은 실제 엔진의 추력 특성을 반영합니다. 저스로틀 영역에서는 추력이 거의 선형이지만, 고스로틀(군용/애프터버닝) 영역에서는 훨씬 가파른 추력 증가를 보입니다.

#### 2.6.2 엔진 동역학 (1차 지연)

실제 추력 P_a는 명령 추력 P_c에 대해 1차 지연계로 응답:

```
dot(P_a) = (1/tau_eng) * (P_c - P_a)
```

시간 상수 tau_eng는 비선형적이며, P_c와 P_a에 의존:

```
1/tau_eng = 5                              (if P_c >= 50 and P_a >= 50)
1/tau_eng = 1/tau_eng*                     (otherwise)

1/tau_eng* = 1                             (if (P_c - P_a) <= 25)
1/tau_eng* = 1.9 - 0.039*(P_c - P_a)       (if 25 < (P_c - P_a) < 50)
1/tau_eng* = 0.1                           (if (P_c - P_a) >= 50)
```

**정당성**: 엔진 추력은 연료 분사량 변화에 따라 지연을 보입니다. 시간 상수가 추력 차이에 의존하는 것은 실제 가스터빈 엔진의 추력 응답 특성(저스로틀과 고스로틀에서 다른 동역학)을 반영합니다.

#### 2.6.3 추력 계산

생성된 추력 F_T는 실제 추력 설정 P_a, 마하 수 M, 고도 h의 함수:

```
F_T = T_idle + (T_mil - T_idle) * (P_a / 50)          (if P_a < 50)
F_T = T_mil + (T_max - T_mil) * (P_a - 50) / 50      (if P_a >= 50)
```

- T_idle: 공회전 추력
- T_mil: 군용(최대 비애프터버닝) 추력
- T_max: 애프터버닝 최대 추력

비행 봉형: 0 <= M <= 1, 0 <= h <= 15,240 m

**정당성**: 추력은 일반적으로 선형 보간을 통해 추력 맵(lookup table)에서 얻습니다. NASA-TM-78335 [28] 및 Delft University [29]의 F-16 엔진 데이터를 기반으로 합니다.

### 2.7 환경 모델

#### 2.7.1 ISA 대기 모델

국제 표준 대기(ISA) 모델은 고도에 따른 대기 특성을 기술합니다. 대류권(11,000 m 이하)에서는 온도 경사도가 일정합니다:

**표준 온도 경사도**: L = -0.0065 K/m

**해수면 표준 조건**:

- T_0 = 288.15 K
- p_0 = 101325 Pa
- rho_0 = 1.225 kg/m^3
- g = 9.80665 m/s^2
- R = 287.05 J/(kg*K)

**대류권 온도, 압력, 밀도**:

```
T(h) = T_0 + L*h
p(h) = p_0 * (T(h)/T_0)^(-g/(R*L))
rho(h) = p(h) / (R * T(h))
```

**정당성**: ISA 모델은 이상기체 방정식(p = rho*R*T)과 hydrostatic equilibrium을 결합하여 유도됩니다. 온도가 고도에 따라 선형적으로 감소한다고 가정하면, 압력과 밀도는 지수 함수 형태로 표현됩니다.

**동압(Dynamic Pressure)**: q = 1/2 * rho(h) * V^2

#### 2.7.2 WGS-84 중력 모델

지구 타원체 모양으로 인한 중력 가속도의 위도/고도 의존성:

**해수면 중력 가속도**:

```
g_0(phi) = 9.780327 * (1 + 0.0053024 * sin^2(phi) - 0.0000058 * sin^2(2*phi))
```

**고도/위도 중력**:

```
g(h, phi) = g_0(phi) * (R_E / (R_E + h))^2
```

- R_E ~= 6,371,000 m: 지구 평균 반경

**정당성**: WGS-84 모델은 지구의 타원체 형태와 질량 분포를 고려하여 중력을 근사합니다. 고도가 증가하면 중력은 제곱 반비례적으로 감소합니다.

#### 2.7.3 Dryden 풍난류 모델

Dryden 모델은 대기 난류를 필터링된 백색 잡음 과정으로 표현합니다:

**종방향 성분**:

```
H_u(s) = sigma_u * sqrt(2*L_u / (pi*V)) * 1 / (1 + (L_u/V)*s)
```

**측방향 성분**:

```
H_v(s) = sigma_v * sqrt(3*L_v / (pi*V)) * (1 + (2/3)*(L_v/V)*s) / (1 + (L_v/V)*s)^2
```

**수직방향 성분**:

```
H_w(s) = sigma_w * sqrt(3*L_w / (pi*V)) * (1 + (2/3)*(L_w/V)*s) / (1 + (L_w/V)*s)^2
```

- sigma: 난류 강도
- L: 난류 스케일 길이
- V: 대기속도

**정당성**: Dryden 모델은 무작위 난류를 1차/2차 전달함수로 모델링합니다. 이는 실제 대기 난류의 공간적 상관관계를 적절히 근사하며, 고정익 항공기의 강건성 평가에 널리 사용됩니다.

## 3. 제어기 설계

본 장에서는 F-16 전투기의 자세 제어를 위한 PID, NDI, INDI 제어기를 설계합니다. 계층적 제어 구조(외부 루프: 자세 각도, 내부 루프: 각속도)를 채택하며, NDI와 INDI의 수학적 유도 및 비교를 상세히 기술합니다.

### 3.1 계층적 제어 구조 개요

현대 항공기 제어 시스템은 일반적으로 **다층 피드백 루프**로 구성됩니다:

- **외부 루프(Outer Loop)**: 느린 동역학 - 자세 각도(theta, phi), 고도, 항로
- **내부 루프(Inner Loop)**: 빠른 동역학 - 각속도(p, q, r), 선가속도

이러한 분리를 통해 각 루프는 서로 다른 시간 척도에서 동작하며, 내부 루프가 외부 루프의 명령을 신속하게 추적합니다.

### 3.2 PID 제어기

#### 3.2.1 기본 형태

PID 제어기는 다음과 같이 표현됩니다:

```
u(t) = K_P * e(t) + K_I * integral(e(tau) dtau) + K_D * de(t)/dt
```

- e(t) = r(t) - y(t): 추적 오차
- K_P, K_I, K_D: 비례, 적분, 미분 이득

#### 3.2.2 F-16 자세 제어에의 적용

PID 제어기는 일반적으로 **SISO(Single Input Single Output)** 구성 또는 **계단식(Cascaded)** 구조로 사용됩니다.

**계단식 PID 구조 (피치 채널 예시)**:

1. **외부 루프**: 피치 각(theta) 오차 -> K_P_theta -> 원하는 피치율(q_d)
2. **내부 루프**: 피치율(q) 오차 -> K_P_q + K_I_q -> 엘리베이터 편각(delta_e)

```
[theta_ref] -> (+) -> [K_P_theta] -> [q_d] -> (+) -> [K_P_q + K_I_q] -> [delta_e] -> [항공기] -> [theta, q]
                  ^                                                          |
                  |__________________________________________________________|
```

**정당성**: 계단식 구조는 내부 루프가 외부 루프보다 훨씬 빠르게 응답하도록 설계됩니다. 이를 통해 외부 루프는 내부 루프의 동역학을 "투명하게" 보고, 전체 시스템은 외부 루프의 느린 동역학만으로 근사됩니다.

#### 3.2.3 PID의 한계

- **비선형 보상 불가**: 정상 상태 근처에서만 양호한 성능
- **축간 결합 무시**: 롤 명령이 피치에 영향을 주는 등의 결합을 처리하지 못함
- **게인 스케줄링 필요**: 넓은 비행 봉형을 커버하려면 여러 운전점에서 개별 튜닝 필요
- **외란에 취약**: 예측하지 못한 공기역학 변화에 민감

### 3.3 NDI (Nonlinear Dynamic Inversion)

#### 3.3.1 이론적 배경

NDI는 **피드백 선형화(feedback linearization)**의 한 형태로, 비선형 시스템을 완전히 선형화하여 선형 제어 이론을 적용할 수 있게 합니다.

일반 비선형 상태공간 시스템:

```
dot(x) = f(x) + g(x) * u
```

- x in R^n: 상태 벡터
- u in R^m: 제어 입력
- f(x): 드리프트(비선형) 동역학
- g(x): 제어 결합 행렬 (control coupling matrix / control effectiveness matrix)

**출력 y의 시간 미분** (상대차수 1인 경우):

```
dot(y) = L_f y + L_g y * u
```

- L_f y: 출력 y에 대한 f의 **Lie 미분** (방향 도함수)
- L_g y: 출력 y에 대한 g의 **Lie 미분**

**Lie 미분의 정의**:

```
L_f y = (partial y / partial x) * f(x)
L_g y = (partial y / partial x) * g(x)
```

**정당성**: 출력 y = h(x)의 시간 미분은 연쇄 법칙(chain rule)에 의해 dot(y) = (partial y/partial x) * dot(x) = (partial y/partial x) * (f(x) + g(x)*u) = L_f y + L_g y * u 입니다. 이는 상태 방정식의 비선형성을 출력 미분에 직접 반영한 결과입니다.

#### 3.3.2 NDI 제어 법칙

L_g y가 비특이(invertible)하다고 가정하면, 비선형 항을 소거하고 원하는 선형 동역학을 강제하는 제어 입력:

```
u = (L_g y)^(-1) * (-L_f y + v)
```

- v: 가상 입력 (선형 제어기로 설계)

**정당성**: 위 제어 법칙을 dot(y) = L_f y + L_g y * u에 대입하면:

```
dot(y) = L_f y + L_g y * [(L_g y)^(-1) * (-L_f y + v)]
       = L_f y - L_f y + v
       = v
```

따라서 출력 y의 동역학은 완전히 선형화되어 dot(y) = v가 됩니다. 이는 "정확한 모델"이 있다는 가정 하에 비선형 항을 완벽히 소거함을 보장합니다.

#### 3.3.3 F-16 피치 채널에의 적용

F-16의 회전 동역학에서 피치 축 방정식은 다음과 같이 쓸 수 있습니다:

```
dot(q) = f_q(x) + g_q(x) * delta_e
```

- f_q(x): 비선형 공기역학 및 관성 항 (알려진 모델)
- g_q(x): 엘리베이터의 제어 효과 계수 (알려진 모델)
- delta_e: 엘리베이터 편각 (제어 입력)

**NDI 제어 법칙 (피치 채널)**:

```
delta_e = (1 / g_q(x)) * (-f_q(x) + v_q)
```

**가상 입력 v_q의 설계**:

외부 루프에서 원하는 피치율을 생성하고, 내부 루프에서 이를 추적합니다. 1차 오차 감소 동역학을 원할 때:

```
v_q = -k_q * (q - q_ref)
```

- k_q > 0: 수렴율을 결정하는 설계 파라미터
- q_ref: 외부 루프에서 생성된 원하는 피치율

**정당성**: v_q를 원하는 가속도로 보면, dot(q) = v_q = -k_q(q - q_ref)는 1차 시스템의 오차 감소 방정식입니다. 이는 q가 q_ref로 지수함수적으로 수렴함을 보장하며, 시간 상수는 1/k_q입니다.

#### 3.3.4 F-16 롤 채널에의 적용

롤 축도 동일한 구조:

```
dot(p) = f_p(x) + g_p(x) * delta_a
```

```
delta_a = (1 / g_p(x)) * (-f_p(x) + v_p)
```

```
v_p = -k_p * (p - p_ref)
```

- delta_a: 에일러론 편각
- p_ref: 외부 루프에서 생성된 원하는 롤율

#### 3.3.5 NDI의 장점

- **비선형 완전 소거**: 정확한 모델 하에서 모든 비선형성을 제거
- **축간 결합 해제**: 각 축을 독립적으로 제어 가능
- **선형 제어 이론 적용**: 선형화된 시스템에 대해 잘 알려진 최적/강건 제어 기법 사용 가능
- **빠른 응답**: 비선형 지연이 없으므로 빠른 추적 성능

#### 3.3.6 NDI의 한계 및 문제점

| 한계 | 설명 |
|---|---|
| **모델 의존성** | f(x), g(x)의 정확한 전체 모델이 필요 |
| **역행렬 조건** | L_g y가 비특이해야 함 (일부 비행 조건에서 특이 가능) |
| **센서 노이즈 증폭** | Lie 미분 계산 시 상태 미분에서 노이즈 증폭 |
| **외란 취약** | 모델 오차 시 성능 저하 또는 불안정 |
| **액추에이터 미고려** | 속도 제한/포화 동역학 미반영 |
| **실시간 계산 부담** | 고차 Lie 미분의 실시간 계산량 큼 |

**정당성**: NDI의 핵심 가정은 dot(y) = L_f y + L_g y * u에서 f(x)와 g(x)를 "완벽히" 알고 있다는 것입니다. 실제로는 공기역학 계수의 오차, 질량 변화, 구조적 탄성 등으로 인해 모델과 실제 동역학 사이에 차이가 존재합니다. 이 차이는 NDI 제어 입력에 직접 반영되어 오차가 그대로 출력에 전달됩니다.

### 3.4 INDI (Incremental Nonlinear Dynamic Inversion)

#### 3.4.1 INDI의 동기 (Motivation)

NDI의 핵심 약점은 **전체 모델 의존성**입니다. 실제 시스템은 다음과 같은 불확실성을 가집니다:

- 공기역학 계수의 오차 및 변화
- 질량/관성의 변화 (연료 소모, 무장 탑재)
- 구조적 탄성 및 진동
- 외란 (풍난류, 돌풍)
- 액추에이터 지연 및 포화

INDI는 이러한 문제를 **센서 기반 증분 접근**으로 해결합니다. 전체 모델을 역전시키는 대신, **"직전 상태에서의 국소적 증분 관계"**만 역전시킵니다.

#### 3.4.2 일반 비선형 시스템에서의 INDI 유도

비선형 시스템:

```
dot(x) = f(x) + G(x) * u
```

출력 y = h(x)의 2차 미분:

```
ddot(y) = (partial h / partial x) * dot(f(x) + G(x)*u)
        = (partial h / partial x) * [dot(f(x)) + dot(G(x))*u + G(x)*dot(u) + ...]
```

**INDI의 핵심 아이디어**: 위의 복잡한 전체 식을 계산하는 대신, **증분 근사**를 사용합니다.

입력의 작은 변화 delta_u에 대한 출력 가속도의 변화:

```
delta_ddot(y) ≈ G_bar * delta_u
```

- G_bar: 제어 효과 행렬 (상수 또는 느리게 변화하는 것으로 가정)
- delta_u = u - u_0: 이전 입력 u_0에 대한 증분

**정당성**:泰勒 전개(Taylor expansion)를 상태-입력 공간에서 수행하면, 작은 증분에 대해 1차 항만 남깁니다:

```
ddot(y) ≈ ddot(y_0) + (partial ddot(y)/partial u) * delta_u
```

여기서 (partial ddot(y)/partial u) = G_bar는 제어 효과 행렬이며, 이는 전체 비선형 함수 f(x)와 G(x)의 복잡한 형태에 덜 민감하게(robustly) 추정할 수 있습니다.

#### 3.4.3 INDI 제어 법칙

원하는 출력 가속도 nu를 달성하기 위한 제어 입력 증분:

```
delta_u = G_bar^(-1) * (nu - ddot(y_0))
```

```
u = u_0 + delta_u
```

- ddot(y_0): 직전 시간 스텝에서 측정(또는 추정)된 출력 가속도
- nu: 외부 루프에서 생성된 **원하는 출력 가속도 (가상 입력)**

**정당성**: 위 식을 delta_ddot(y) ≈ G_bar * delta_u에 대입하면:

```
delta_ddot(y) = G_bar * [G_bar^(-1) * (nu - ddot(y_0))]
              = nu - ddot(y_0)
```

따라서 새로운 출력 가속도는:

```
ddot(y) = ddot(y_0) + delta_ddot(y) = ddot(y_0) + (nu - ddot(y_0)) = nu
```

즉, 출력의 가속도가 정확히 원하는 가속도 nu로 설정됩니다. 이는 전체 모델 f(x)의 정확한 형태를 알 필요 없이, 오직 **직전 가속도 측정값**과 **국소 제어 효과**만으로 성립합니다.

#### 3.4.4 F-16 피치 축에의 INDI 적용

피치 축 동역학:

```
dot(q) = (1/I_yy) * M_y(delta_e) + f_q_other(x)
```

여기서 M_y는 피치 모멘트이며, delta_e에 대해 거의 선형적으로 의존합니다. 정상 상태 근처에서:

```
delta_dot(q) ≈ g_bar_q * delta_delta_e
```

- g_bar_q = partial(dot(q))/partial(delta_e) ≈ (1/I_yy) * partial(M_y)/partial(delta_e)

**INDI 제어 법칙 (피치 채널)**:

```
delta_delta_e = (1 / g_bar_q) * (nu_q - dot(q_0))
```

```
delta_e = delta_e_0 + delta_delta_e
```

- nu_q: 원하는 피치 가속도 (외부 루프 가상 입력)
- dot(q_0): 직전 시간 측정 피치 가속도
- g_bar_q: 엘리베이터의 제어 효과 계수

**정당성**: 피치 모멘트 M_y는 어택 각 alpha와 엘리베이터 편각 delta_e의 함수입니다. 정상 상태 근처에서 테일러 전개하면:

```
M_y(alpha, delta_e) ≈ M_y(alpha_0, delta_e_0) + (partial M_y/partial alpha)*delta_alpha + (partial M_y/partial delta_e)*delta_delta_e
```

증분 입력 delta_delta_e에 의한 모멘트 변화는 (partial M_y/partial delta_e)*delta_delta_e에 비례하며, 이를 I_yy로 나눈 값이 피치 가속도 증분입니다. 따라서 g_bar_q = (1/I_yy)*(partial M_y/partial delta_e)는 실제 비행 실험에서 추정하거나, 선형화된 공기역학 모델로부터 계산할 수 있습니다.

#### 3.4.5 F-16 롤/요 축에의 INDI 적용

롤 축:

```
delta_delta_a = (1 / g_bar_p) * (nu_p - dot(p_0))
```

요 축:

```
delta_delta_r = (1 / g_bar_r) * (nu_r - dot(r_0))
```

- g_bar_p = partial(dot(p))/partial(delta_a)
- g_bar_r = partial(dot(r))/partial(delta_r)

#### 3.4.6 제어 효과 계수 g_bar의 결정

제어 효과 행렬 G_bar의 성분들은 다음 방법으로 얻을 수 있습니다:

1. **비행 실험/시뮬레이션**: 작은 제어 입력 변화에 대한 각가속도 변화를 측정하여 수치 미분
2. **선형화된 공기역학 모델**: 공기역학 계수의 편미분으로부터 이론적 계산
3. **온라인 추정**: 칼만 필터(Kalman Filter) 또는 재귀 최소자승법(RLS)을 이용한 실시간 갱신

**정당성**: g_bar_q = partial(dot(q))/partial(delta_e)는 상태 공간에서의 국소적 민감도입니다. 이는 전체 비선형 함수의 형태보다 훨씬 단순하며, 느리게 변화하는 매개변수로 취급할 수 있습니다. 실제로 g_bar는 비행 조건(속도, 고도)에 따라 천천히 변화하므로, 적응적 알고리즘으로 추적할 수 있습니다.

#### 3.4.7 센서 요구사항

INDI는 다음 센서 데이터를 필요로 합니다:

- **각속도**: p, q, r (자이로스코프)
- **각가속도**: dot(p), dot(q), dot(r) (자이로스코프 미분 또는 각가속도계)
- **제어 입력 직전 값**: u_0 (이전 제어 명령)

**각가속도 추정 방법**:

1. **수치 미분**: 각속도 신호의 차분 (노이즈 증폭 우려)
2. **고역통과 필터 + 미분**: 노이즈 필터링 후 미분
3. **칼만 필터**: 상태 추정기를 이용한 최적 추정
4. **각가속도계 직접 측정**: MEMS 각가속도 센서 사용

**정당성**: INDI의 핵심은 "직전 측정값"을 사용한다는 것입니다. 따라서 각가속도를 측정/추정하는 지연이 제어 주기에 비해 작아야 합니다. 1000 Hz 샘플링에서는 한 스텝 지연이 1ms로 무시 가능하지만, 센서 자체의 필터링 지연은 고려해야 합니다.

#### 3.4.8 INDI의 장점

| 장점 | 설명 |
|---|---|
| **모델 의존도 낮음** | 전체 f(x), G(x) 대신 G_bar만 필요 |
| **외란 강건성** | 실시간 센서 피드백으로 외란 자동 보상 |
| **계산량 적음** | 고차 Lie 미분 불필요, 단순 행렬 곱셈 |
| **기존 시스템 통합 용이** | PID 외부 루프 위에 모듈로 추가 가능 |
| **액추에이터 포화 강건** | 증분 제어는 포화에 덜 민감 |
| **적응성** | RLS/Kalman으로 G_bar 온라인 갱신 가능 |

#### 3.4.9 INDI의 한계

| 한계 | 설명 |
|---|---|
| **고품질 센서 필수** | 낮은 노이즈, 빠른 응답 각가속도 센서 필요 |
| **국소 선형 가정** | 큰 기동에서는 증분 근사가 무너질 수 있음 |
| **액추에이터 동역학 무시** | 빠른 액추에이터 지연은 성능 저하 유발 |
| **G_bar 추정 오차** | 제어 효과 계수 추정 오차는 여전히 영향 |
| **샘플링 주파수 의존** | 낮은 주파수에서는 증분 근사 정확도 감소 |

#### 3.4.10 NDI vs INDI 비교 요약

| 기준 | NDI | INDI |
|---|---|---|
| **모델 의존성** | 높음 (전체 f(x), g(x) 필요) | 낮음 (G_bar만 필요) |
| **외란 강건성** | 중간 | 높음 |
| **센서 요구사항** | 낮음 (각속도만으로 가능) | 높음 (각가속도 필요) |
| **계산 복잡도** | 높음 (Lie 미분 실시간 계산) | 중간 (행렬 곱셈) |
| **구현 난이도** | 높음 | 중간 |
| **액추에이터 포화** | 민감 | 비교적 강건 |
| **실용성** | 연구/시뮬레이션 중심 | 실제 항공기 적용 가능 |

### 3.5 외부 루프 설계 (가상 입력 생성)

NDI와 INDI 모두 내부 루프를 선형화하지만, 외부 루프는 원하는 가상 입력 nu를 생성해야 합니다. 본 연구에서는 **PI(Proportional-Integral) 제어기**를 외부 루프에 사용합니다.

#### 3.5.1 PI 제어기 구조

```
nu = K_P * e + K_I * integral(e dt)
```

- e = y_ref - y: 자세 각도 오차 (예: theta_ref - theta)
- nu: 원하는 각가속도 (가상 입력)

**피치 채널 예시**:

```
nu_q = K_P_theta * (theta_ref - theta) + K_I_theta * integral(theta_ref - theta)
```

#### 3.5.2 이득 튜닝

PI 이득은 다음 성능 기준을 만족하도록 튜닝됩니다:

- **상승시간(Rise Time)**: 90% 도달 시간
- **정착시간(Settling Time)**: 오차가 2% 이내로 들어가는 시간
- **과도(Over shoot)**: 최대 초과량
- **안정성 마진**: 게인 마진, 위상 마진

본 연구에서 사용된 PI 이득:

**피치 채널**:

| 제어 루프 | K_P | K_I |
|---|---|---|
| 피치 각(theta) | 10.0 | 0.0 |
| 피치율(q) | 400.0 | 400.0 |

**롤 채널**:

| 제어 루프 | K_P | K_I |
|---|---|---|
| 롤 각(phi) | 4.5 | 0.02 |
| 롤율(p) | 1500.0 | 2500.0 |

- **샘플링 주파수**: 1000 Hz (dt = 0.001 s)

- **비행 조건**: 정상 수평 비행(Trim) 상태에서의 자세 명령 추적

### 4.2 성능 평가 지표

다음 지표를 사용하여 정량적 성능 평가를 수행합니다:

#### 4.2.1 RMSE (Root Mean Square Error)

```
RMSE = sqrt( (1/N) * sum_{i=1}^{N} (y_ref(i) - y(i))^2 )
```

- 추적 성능의 전반적 정확도를 측정
- 단위: deg (도)

#### 4.2.2 ISE (Integral of Squared Error)

```
ISE = integral_0^T (y_ref(t) - y(t))^2 dt
```

- 시간에 따른 누적 오차의 크기
- 단위: deg^2 * s

#### 4.2.3 평균 오차 (Mean Error)

```
e_mean = (1/N) * sum_{i=1}^{N} (y_ref(i) - y(i))
```

- 정상 상태 오차(steady-state error) 및 바이어스 평가
- 단위: deg

#### 4.2.4 지연 시간 (Delay Time)

```
t_delay = t_{50%} - t_{command}
```

- 명령의 50%에 도달하는 데 걸리는 시간
- 단위: s (초)

### 4.3 정상 조건(Nominal) 성능 평가

| 롤 각(phi) | INDI | 1.2085 | 7.3036 | 0.7967 | 0.2160 |
| 롤율(p) | NDI | **0.0014** | **0.00001** | 0.0000 | 0.0170 |
| 롤율(p) | INDI | 0.0609 | 0.0186 | 0.0005 | 0.0180 |

**분석**:
- 롤 각(phi) 추적에서는 NDI와 INDI가 **유사한 수준**의 성능을 보임
- 롤율(p)에서는 NDI가 INDI보다 낮은 RMSE를 기록 (내부 루프 성능)
- 롤 기동 중 피치 각(theta)의 유도 응답은 INDI에서 더 억제되는 경향
- 이는 INDI의 증분 제어가 축간 결합에 덜 민감함을 시사

### 4.4 강건성 평가 (모델 불확실성)

비현실적 조건에서의 제어기 성능을 평가하기 위해 인위적인 모델 불확실성을 추가합니다.

#### 4.4.1 적용된 모델 불확실성

**엘리베이터(delta_e) 및 에일러론(delta_a)에 공통 적용**:

| 구성 요소 | 설명 | 값 |
|---|---|---|
| 백색 잡음 세기 | 가한 잡음의 크기 | 10^(-1) |
| 잡음 샘플링 시간 | 잡음 업데이트 주기 | 0.01 s |
| 상수 바이어스 | 제어 명령에 추가된 고정 오프셋 | 5도 |
| 포화 한계 | 제어 표면의 최대/최소 편각 | +/- 25도 |

**정당성**: 위 불확실성은 다음 실제 상황을 시뮬레이션합니다:
- **백색 잡음**: 센서 노이즈, 액추에이터 전기적 잡음, 기류 난류
- **상수 바이어스**: 캘리브레이션 오차, 기계적 백래시, 액추에이터 드리프트
- **포화**: 액추에이터의 물리적 한계, 서보 모터 최대 토크

#### 4.4.2 피치 채널 강건성 비교

**시뮬레이션 결과 플롯** (논문 Figure 4.19 ~ 4.21 참고):
- 불확실성 하에서의 피치 각(theta) 추적
- 불확실성 하에서의 피치율(q) 응답
- 불확실성 하에서의 엘리베이터 편각(delta_e)

**성능 지표 비교 (불확실성 조건)**:

| 변수 | 제어기 | RMSE [deg] | ISE [deg^2*s] |
|---|---|---|---|
| 피치 각(theta) | NDI | 0.6689 | 0.3137 |
| 피치 각(theta) | INDI | **0.5127** | **0.1843** |

**정상 조건 대비 성능 변화**:

| 제어기 | RMSE 변화율 | ISE 변화율 |
|---|---|---|
| NDI | +20.6% | +1.9% |
| INDI | +10.8% | +22.8% |

**분석**:
- INDI가 NDI보다 불확실성 하에서 **RMSE 23.4% 낮음** (0.6689 -> 0.5127)
- INDI가 NDI보다 **ISE 41.2% 낮음** (0.3137 -> 0.1843)
- NDI는 정상->불확실성에서 RMSE가 20.6% 증가하는 반면, INDI는 10.8%만 증가
- **INDI가 모델 불확실성에 훨씬 덜 민감**

#### 4.4.3 롤 채널 강건성 비교

**시뮬레이션 결과 플롯** (논문 Figure 4.22 ~ 4.24 참고):
- 불확실성 하에서의 롤 각(phi) 추적
- 불확실성 하에서의 롤율(p) 응답
- 불확실성 하에서의 에일러론 편각(delta_a)

**성능 지표 비교 (불확실성 조건)**:

| 변수 | 제어기 | RMSE [deg] | ISE [deg^2*s] |
|---|---|---|---|
| 롤 각(phi) | NDI | 1.1118 | 2.8440 |
| 롤 각(phi) | INDI | **0.8541** | **1.6787** |

**정상 조건 대비 성능 변화**:

| 제어기 | RMSE 변화율 | ISE 변화율 |
|---|---|---|
| NDI | -6.3% | -59.6% |
| INDI | -29.3% | -77.0% |

**분석**:
- INDI가 NDI보다 불확실성 하에서 **RMSE 23.2% 낮음** (1.1118 -> 0.8541)
- INDI가 NDI보다 **ISE 41.0% 낮음** (2.8440 -> 1.6787)
- 롤 채널에서 INDI의 강건성 우위가 피치 채널과 유사한 수준
- NDI의 ISE가 정상 조건에서 7.0363이었으나 불확실성에서 2.8440으로 감소한 것은, 바이어스와 포화가 NDI의 진동을 억제한 결과로 해석될 수 있음 (성능 향상이 아닌 "억제" 효과)

### 4.5 제어 입력 평활도 분석

#### 4.5.1 엘리베이터 명령 비교

시뮬레이션에서 관찰된 엘리베이터 편각 명령의 특성:

- **NDI**: 빠른 초기 응답과 큰 순간 편각
- **INDI**: 더 부드러운 응답과 작은 순간 편각

**의의**: 부드러운 제어 입력은 다음과 같은 실제 이점을 제공합니다:
- 액추에이터 모터의 전기적/기계적 부하 감소
- 연료 효율 개선 (항공기의 경우)
- 구조적 진동 및 피로 감소
- 승객/조종사의 승차감 향상

#### 4.5.2 에일러론 명령 비교

롤 채널에서도 동일한 경향이 관찰됩니다. INDI의 에일러론 명령은 NDI보다:
- 초기 과도 응답이 작음
- 정상 상태 변동이 적음
- 포화에 도달하는 빈도가 낮음

### 4.6 축간 결합(Cross-Coupling) 분석

롤 기동(phi 명령) 시 피치 각(theta)의 유도 응답을 비교:

- **NDI**: 롤 기동 중 피치 각이 상당히 변동
- **INDI**: 롤 기동 중 피치 각 변동이 더 억제됨

**정당성**: F-16의 회전 동역학에는 비선형 결합 항이 존재합니다 (예: I_xz * p * q 항). NDI는 개별 축만 고려하는 경향이 있어, 다른 축의 명령에 의한 간접적 영향을 완벽히 보상하지 못합니다. INDI는 실시간 센서 피드백을 사용하여 모든 축의 현재 상태를 반영하므로, 축간 결합에 의한 간접 영향을 더 효과적으로 처리합니다.

### 4.7 종합 성능 평가

#### 4.7.1 정상 조건 종합

| 채널 | 우수 제어기 | 주요 이유 |
|---|---|---|
| 피치 | **INDI** | RMSE, ISE, 지연 시간 모두 우수 |
| 롤 | **유사** | RMSE/ISE에서 큰 차이 없음, NDI가 롤율에서 약간 우수 |

#### 4.7.2 불확실성 조건 종합

| 채널 | 우수 제어기 | 주요 이유 |
|---|---|---|
| 피치 | **INDI** | RMSE 23.4% 감소, ISE 41.2% 감소 |
| 롤 | **INDI** | RMSE 23.2% 감소, ISE 41.0% 감소 |

#### 4.7.3 핵심 결론

1. **정상 조건**: INDI가 NDI와 비슷하거나 약간 우수한 성능
2. **불확실성 조건**: INDI가 NDI보다 **현저히 강건**함
3. **정량적 개선**: 불확실성 하에서 RMSE 기준 20~30%, ISE 기준 40% 이상 개선
4. **제어 입력 품질**: INDI의 제어 입력이 더 부드럽고 액추에이터에 부담 적음
5. **축간 결합**: INDI가 롤 기동 중 피치 변동을 더 잘 억제

## 5. 결론 및 향후 연구

### 5.1 결론

본 논문에서는 F-16 Fighting Falcon 전투기의 자세 제어에 대해 **비선형 동역학 역전(NDI)**과 **증분 비선형 동역학 역전(INDI)**을 비교 연구하였습니다. 6-DoF 비선형 F-16 모델을 MATLAB/Simulink에 구축하고, 피치 및 롤 채널에 대해 정상 조건과 모델 불확실성 조건에서의 성능을 정량적으로 평가하였습니다.

#### 5.1.1 주요 연구 결과

**1. NDI의 특성**

- 정확한 모델이 제공되는 정상 조건에서는 양호한 추적 성능을 보임
- 피드백 선형화를 통해 비선형 항을 완벽히 소거하고, 선형 제어 이론을 직접 적용 가능
- 그러나 모델 불확실성(공기역학 오차, 액추에이터 바이어스, 잡음, 포화)에 대해 성능이 현저히 저하됨
- 전체 비선형 모델의 정확한 지식이 필요하므로 실제 항공기 적용에 한계 존재

**2. INDI의 특성**

- 정상 조건에서 NDI와 비슷하거나 약간 우수한 성능
- 모델 불확실성 조건에서 NDI 대비 **현저히 강건**함:
  - 피치 채널: RMSE 23.4% 감소, ISE 41.2% 감소
  - 롤 채널: RMSE 23.2% 감소, ISE 41.0% 감소
- 전체 모델 f(x)의 정확한 형태를 알 필요 없이, **직전 센서 측정값**과 **국소 제어 효과**만으로 동작
- 액추에이터 포화 및 외란에 덜 민감
- 기존 PID 기반 구조 위에 모듈형으로 덧씌울 수 있어 실용적

**3. 정량적 성능 비교 요약**

| 조건 | 채널 | NDI RMSE | INDI RMSE | 개선율 |
|---|---|---|---|---|
| 정상 | 피치 | 0.5544 | 0.4627 | 16.5% |
| 정상 | 롤 | 1.1862 | 1.2085 | -1.9% |
| 불확실성 | 피치 | 0.6689 | 0.5127 | 23.4% |
| 불확실성 | 롤 | 1.1118 | 0.8541 | 23.2% |

**4. INDI의 실용적 이점**

- **모델 의존도 감소**: 비행기의 정확한 비선형 모델 없이 제어 가능
- **센서 기반 적응**: 실시간 각가속도 측정으로 외란 자동 보상
- **계산 효율성**: 고차 Lie 미분 계산 불필요
- **기존 시스템 통합 용이**: PID 외부 루프 + INDI 내부 루프 구조로 마이그레이션 가능
- **제어 입력 품질**: 더 부드러운 제어 표면 동작

#### 5.1.2 이론적 기여

본 연구는 INDI의 이론적 장점을 **포괄적인 시뮬레이션**을 통해 실증하였습니다. 특히:

- F-16과 같은 **고기동 전투기**의 불안정 비선형 동역학에 INDI를 적용
- **정량적 성능 지표**(RMSE, ISE, 평균 오차, 지연 시간)를 사용한 객관적 비교
- **모델 불확실성**(잡음 + 바이어스 + 포화)의 조합 하에서의 강건성 평가
- **축간 결합** 효과에 대한 INDI의 우수성 분석

### 5.2 향후 연구 방향

#### 5.2.1 하드웨어 인 더 루프(HIL) 실험

시뮬레이션 결과를 실제 항공 전자 시스템으로 확장:

- **온보드 처리 한계**: 임베디드 컴퓨터에서 INDI의 실시간 계산 가능성 평가
- **센서 지연**: 실제 IMU 센서의 필터링 지연이 INDI 성능에 미치는 영향
- **샘플링 주파수**: 1000 Hz 이하에서의 INDI 성능 저하 평가

#### 5.2.2 적응형 INDI

INDI의 강건성을 더욱 향상시키기 위한 적응 메커니즘:

- **온라인 G_bar 추정**: 칼만 필터 또는 재귀 최소자승법을 이용한 제어 효과 행렬 실시간 갱신
- **신경망 증강**: 비선형 보상 항을 신경망으로 학습하여 증분 근사의 유효 범위 확장
- **강화학습 기반 튜닝**: 시뮬레이션 기반 자동 이득 튜닝

#### 5.2.3 제어 할당(Control Allocation) 개선

과다 액추에이터(Over-actuated) 시스템에서의 INDI 확장:

- **의사 제어 헤징(Pseudo-Control Hedging)**: 액추에이터 포화 시 외부 루프에 피드백
- **비선형 제어 할당**: INDI와 결합된 최적 제어 표면 분배
- **결함 허용(Fault-Tolerant) 제어**: 액추에이터 손상 시 자동 재구성

#### 5.2.4 확장 비행 봉형 평가

현재 연구는 주로 정상 수평 비행 근처의 자세 제어에 초점을 맞추었습니다. 향후 연구에서는:

- **고 어택 각(alpha) 비행**: 실속/실속 이후 영역에서의 INDI 성능
- **초음속 비행**: 마하 수 변화에 따른 공기역학 급변 상황
- **풍난류 및 돌풍**: Dryden 모델을 이용한 외란 응답 상세 분석
- **착륙/이륙**: 저속, 고 어택 각 조건에서의 INDI 적용

#### 5.2.5 인증 및 안전성 평가

항공기 제어 시스템의 실제 적용을 위해서는:

- **안정성 증명**: INDI의 폐쇄 루프 안정성에 대한 이론적 분석
- **게인 마진/위상 마진**: 주파수 영역에서의 강건성 마진 계산
- **Monte Carlo 시뮬레이션**: 다양한 초기 조건 및 파라미터 불확실성 하에서의 통계적 성능 평가
- **DO-178C/DO-331**: 항공 소프트웨어 인증 기준에 대한 적합성 검토

### 5.3 최종 정리

본 연구를 통해 다음이 검증되었습니다:

> **INDI(증분 비선형 동역학 역전)는 F-16과 같은 고기동 전투기의 자세 제어에서 NDI(전통적 비선형 동역학 역전)보다 모델 불확실성과 외란에 대해 현저히 강건하며, 기존 PID 기반 제어 구조 위에 모듈형으로 통합할 수 있는 실용적인 대안이다.**

INDI는 전체 모델의 정확한 지식이 불가능한 현실적 상황에서, 센서 기반 증분 접근을 통해 안정적이고 정확한 제어를 제공합니다. 이는 현대 및 미래의 무인/유인 항공기, 특히 높은 기동성과 강건성을 요구하는 전투기 및 UAV 플랫폼에 적합한 제어 기법임을 시사합니다.
