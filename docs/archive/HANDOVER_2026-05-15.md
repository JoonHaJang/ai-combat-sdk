## 2. 이번 세션 채택된 모델 수정 (모두 G1 게이트 통과)

### Stage 1 (vs simple — 1W4L → 10W0L0D)
1. **`grad_V_PN` speed term**: `(V_p−V_c)²` → `(V_p−V_e)²` — m_2 PN tracking mode 의 speed objective 정정. V_corner(선회) 가 아니라 V_e(적 속도) 매칭으로 WEZ station-keep. `tools/basis/gradient_approximators.py`.
2. **3D ATA 항**: `½·ATA_horiz² + ½·ATA_vert²` — 수직 aim 항 추가, gamma 채널 구동. `ATA_vert = atan2(dh, r_xy)`. 같은 파일.
3. **DefensiveBreak predictive 트리거**: `enm_in_wez` (reactive) ∨ `ATA>100 ∧ dist<3000` (predictive, v11 IsLostPursuit 이식). `examples/pursuit_chase_v1/nodes/branch_dispatcher.py`.
4. **`EnergyRecovery` 분기 + 히스테리시스**: V_p<360 진입, V_p>400 탈출 (chatter 차단). command `{corner:1.0}` 순수 직진가속 (선회 섞으면 즉시 재고갈). 히스테리시스가 핵심 — 버퍼 쌓고 교전.

### Stage 2 (vs defensive — 데미지 0 → 2승 결정적)
5. **`grad_V_PN` speed target dist-의존**: 근거리(≤WEZ_OUTER=3000) V_e-매칭 / 원거리(>8000) V_sprint(480). 선형 blend. (V_p−V_e)² 만으론 원거리에서 도망자 속도에 capped → 못 따라잡음 fix.
6. **V_e clamp [160, 480]**: 비-stern 기하에서 `V_e = V_p − closure` 가 폭주(1260kts 측정) → F-16 envelope 로 clamp.
7. **v11 분기 이식 (RT-1 추가완성)**: `OrbitBreak`, `LagPursuit`, `DefensiveBreak`, `ZoomClimb` 분기 + 분기 명령을 ∇V-derived 로 (PLAN §2.6.5 mode-τ mapping).

## 3. 기각된 시도 (12+ 변형 — 단일-tick 프레임 한계 증명)

**Stage 2 (defensive 격파 시도)** — 모두 cumulative 제약(simple 회귀 또는 무효)에 막힘:
- TurnAround 5변형: A0 (no gate), A2 (AA>90), A3 (AA<90), A4 (dist>5000) — 전부 simple 회귀 OR defensive 무효
- ZoomClimb (option C) 단독: 무효 (simple 6W/0L 유지, defensive 2W/4D 동등)
- A2 + C 결합: 무효 (서로 다른 순간 cover 못 함)
- EnergyRecovery 게이트 3변형 (ata<60 / ata<90 / `ata>90∧closure<0`): 전부 simple 회귀 (EnergyRecovery 는 simple load-bearing)
- 선회-유도항력 accel cap (fix #4): 1W5D 회귀 (agent 소극화)
- LDT speed-lag (`grad_V_LDT` 에 V_p 항 추가): defensive 2W → 0W/6D 회귀 (LagPursuit 가 거의-닫은 순간 감속해 kill 차단)

**Stage 3 (aggressive 격파 시도)**:
- DiveAttack 분기 (PE→KE 전환): defensive 2W → 0W/6D 회귀

**V_aa "유분리 추구" 항 재활성 5변형** (사용자 직접 지적한 모델 누락 — 현재 `alpha_aa=0` 비활성):
- B1 dist wide sigmoid (c=4000 w=1500): defensive 6W/0L ★ 하지만 simple 0W/6D 회귀
- B2 dist narrow (c=2500 w=500): 양쪽 회귀
- B3 const 0.5: 양쪽 0W/6D
- B4 V_e-V_p clip-linear: G1 fail (kink)
- B5 V_e-V_p sigmoid: 양쪽 0W/6D

**핵심 패턴**: V_aa 가 "적 6시 추구" → defensive (도망) 에는 도움, simple (추격) 에는 head-on 교전 흐트림. *단일-tick obs 로 적 의도(추격 vs 도망) 분리 불가능.* V_e 추정 자체가 closure-based 점추정이라 비-stern 기하서 garbage.

## 6. 안티-패턴 / 함정 (다음 세션이 반복하지 말 것)

- **단일-tick 분기 조건만으로 simple/defensive 의도 분리 시도** — 12+ 변형이 모두 실패. 의도 신호는 다-tick 시간차분에서 와야 함.

- **V_aa 항 단순 재활성** — alpha_aa>0 의 모든 dist/V_e 기반 게이트가 simple 회귀.
- **`--rounds N` 한 프로세스 측정** — 프로세스 단위 FP 결정성. 별도 프로세스 ≥5회로 분산 측정 필수.
