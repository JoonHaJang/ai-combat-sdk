# 01. 이 프로젝트가 하고자 하는 것

> **한 줄 요약**: F-16 1대1 공중전에서 이기는 AI 조종사를 행동 트리로 만든다.

---

## 1. 무대 — F-16 두 대의 1대1 공중전

이 프로젝트는 **JSBSim** 이라는 실제 비행 물리 시뮬레이터 위에서 돌아갑니다.
JSBSim은 NASA·Stanford 출신들이 만든 오픈소스 비행역학 엔진으로,
중력·양력·항력·G 한계 같은 진짜 물리를 계산합니다.

```
┌──────────────┐         ┌──────────────┐
│  내 AI 에이전트  │  ◄─교전─►  │ 상대 AI 에이전트  │
│ (e.g. eagle1)│          │ (e.g. viper1) │
└──────┬───────┘          └──────┬───────┘
       │ 매 0.2초마다 명령        │
       ▼                         ▼
┌─────────────────────────────────────────┐
│      JSBSim F-16 비행 물리 시뮬레이터        │
│   (헤딩, 고도, 속도, 선회율, G 등 실제 계산)  │
└─────────────────────────────────────────┘
```

두 비행기가 같은 무대(같은 고도·같은 속도)에서 시작해서, **300초(1500틱) 안에
누가 먼저 상대를 격추하는지** 가 승부입니다.

---

## 2. 어떻게 이기는가 — Gun WEZ

이 프로젝트의 무기는 **기관총 하나**. 미사일 없습니다. 따라서 격추하려면
**상대 뒤에 붙어서 정조준** 해야 합니다.

데미지 조건 (둘 다 동시에 만족):

```
ATA < 12°            (내 기수와 상대 사이 각도 — 거의 정조준)
500ft < 거리 < 3000ft  (너무 가까워도 안 됨, 너무 멀어도 안 됨)
```

이 두 조건을 유지하는 시간만큼 데미지가 누적되어 100 HP가 0이 되면 격추.

---

## 3. AI를 어떻게 만드는가 — 행동 트리(Behavior Tree)

AI에게 "이 상황에서 이렇게 해라" 를 가르치는 방식이 **행동 트리** 입니다.

가장 단순한 예시:

```yaml
tree:
  type: Selector              # 위에서 아래로 처음 통과되는 가지를 실행
  children:
    - type: Sequence
      name: 비상_상승
      children:
        - type: Condition
          name: BelowHardDeck   # 너무 낮으면
        - type: Action
          name: ClimbTo          # 즉시 상승

    - type: Sequence
      name: 사격
      children:
        - type: Condition
          name: IsOffensive      # 적 뒤를 잡았으면
        - type: Action
          name: GunAttack        # 사격

    - type: Action
      name: LeadPursuit          # 그 외 — 일단 추격
```

이게 한 비행기의 "두뇌". 매 틱(0.2초)마다 위에서부터 평가해서 어떤 행동을 할지 결정합니다.

---

## 4. 이 프로젝트의 진짜 어려움

단순한 BT는 약한 적은 이기지만 강한 적에게 집니다. 왜?

- **환경이 매번 다름**: 적이 우리 의도를 알면 패턴을 깨려고 함
- **3D 공간**: 수평·수직·속도 다 같이 움직임 → 평면 분석 불충분
- **물리 한계**: F-16의 ω(선회율)이 속도에 따라 변함, 350kts에서 최대
- **게임 이론적 대칭**: 동등 성능 적과 정중앙(canonical) 대치 시 양쪽 모두 최적이면 무승부

그래서 단순 BT 위에 **수학적으로 증명된 BFM(Basic Fighter Maneuvers, 기본
공중기동) 정리** 들을 얹어서, **연속적·적응적**으로 명령을 합성합니다. 이게 최근 작업의 본질.

---

## 5. 그래서 지금 우리가 하는 것

**최근 시도** (2026-04 ~ 05):

1. F-16 vs F-16 표준 시작 조건(canonical)에서 모든 적 정책에 대해 이기는 AI를 만들고자 함
2. BFM 수학 정리 8개 (Bernoulli·Bryson-Ho·Isaacs×2·Boyd·Shaw×2·Pontryagin) 를 코드에 매핑
3. 처음에는 "if 조건이면 이 분기 발동" 식 — 이건 적이 변하면 깨짐 → 폐기
4. 다음 시도: "지금 조건이 얼마나 맞는가"를 0~1 점수(τ)로 매겨 **연속적으로 가중 합성**

**결과**: 시뮬 검증 55 케이스에서 WIN 91% / LOSS 0%. 표준 시작 조건 × 5가지 적 정책 = 5/5 WIN.

자세한 내용은 [03_recent_analysis.md](./03_recent_analysis.md) 에서 자연어로.
