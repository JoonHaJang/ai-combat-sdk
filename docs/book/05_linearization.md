# 5장. 동역학의 선형화 — 비선형을 운영점에서 직선으로

## 학습 목표
이 장을 마치면 다음을 할 수 있다.
- 비행 동역학이 왜 비선형인지, 그런데 왜 선형으로 풀어도 되는지 설명한다.
- 운영점(평형점) 근처에서 비선형 함수를 선형으로 근사하는 과정을 안다.
- 유한차분으로 시스템 행렬 A와 B를 구하는 방법을 안다.
- 선형 근사가 원래 비선형에 대해 무엇을 보장하고 무엇을 보장하지 않는지 안다.

이 장은 토대에서 제어로 넘어가는 다리다. 4장에서 세운 비선형 비행기 위에, 6장의 LQR이 딛고 설
선형 모델을 만든다.

---

## 5.1 비행 동역학은 비선형이다

비행기의 운동 방정식은 비선형이다. 받음각이 커지면 양력 계수가 더 이상 비례하지 않고, 삼각함수
(사인, 코사인)가 자세에 곱해지며, 각속도끼리 곱해지는 항이 있다. 상태를 x, 입력을 u라 하면 동역학은
일반적으로 다음 형태다.

```
x_dot = f(x, u)
```

여기서 f는 비선형 함수다. 비선형 시스템을 직접 최적 제어하는 것은 일반적으로 어렵다. 반면 선형
시스템은 잘 정리된 이론(LQR, 안정성, 마진)이 있다. 그래서 우리는 비선형을 한 점 근처에서 선형으로
바꾼다.

---

## 5.2 운영점 근처에서 직선으로

핵심 발상은 미적분의 기초다. 매끄러운 함수는 한 점 가까이에서 그 점의 접선과 거의 같다. 평형점
(운영점) x0, u0를 잡자. 평형점에서는 x_dot = f(x0, u0) = 0 이다(4장의 trim이 이 점을 준다).
평형점에서 조금 벗어난 양을 델타로 적는다.

```
x = x0 + dx,   u = u0 + du
```

f를 평형점에서 1차 테일러 전개하면 다음과 같다.

```
x_dot = f(x0,u0) + A·dx + B·du + (고차항)
      ≈ A·dx + B·du
```

여기서 A는 f를 상태로 편미분한 행렬(∂f/∂x), B는 입력으로 편미분한 행렬(∂f/∂u)이며, 둘 다 평형점에서
계산한다. 버린 고차항은 델타의 크기 제곱에 비례하므로(O(‖델타‖²)), 평형점 가까이에서는 무시할 만큼
작다. 결과는 익숙한 선형 상태공간이다.

```
dx_dot = A·dx + B·du
```

이것이 우리가 6장에서 LQR을 설계할 대상이다. 그림으로 보면, 비선형 곡선 f를 평형점에서의 접평면
(A, B)으로 바꾼 것이다.

```
  f(x)  비선형 곡선
    │        ╱
    │      ╱   ← 평형점에서의 접선 (선형 근사 A·dx)
    │    ●────────
    │  ╱  x0
    └─────────────── x
       (x0 근처에서 곡선 ≈ 접선)
```

---

## 5.3 그런데 선형으로 풀어도 정말 되는가

좋은 질문이다. 평형점에서 멀어지면 근사가 깨질 텐데, 선형 제어기를 비선형 비행기에 써도 되는
근거는 무엇인가. 답은 세 정리에 있다.

첫째, 테일러 정리가 버린 항의 크기를 보장한다. 고차항은 O(‖델타‖²)이므로 평형점 가까이에서는
2차로 작아진다.

둘째, 하트만-그로브만 정리(Hartman-Grobman)는 평형점이 쌍곡(고유값 실수부가 0이 아님)이면, 비선형
시스템의 국소 거동이 그 선형화와 위상적으로 같다고 말한다. 즉 선형화가 국소 거동의 질적 모습을
충실히 담는다.

셋째, 리아푸노프 간접법(Lyapunov indirect method, Khalil의 정리)이 결정적이다. 선형화 A의 모든
고유값이 좌반평면에 있으면(Hurwitz, 곧 안정이면), 원래 비선형 시스템도 그 평형점에서 국소 점근
안정이다. 다시 말해 우리가 선형 모델에서 안정한 제어기를 설계하면(6장에서 LQR이 A의 고유값을
좌반평면으로 보낸다), 그 제어기는 원래 비선형 비행기에 대해서도 평형점 근처에서 안정함이 증명된다.

정직하게 말하면, 이 보장은 국소적이다. 평형점에서 충분히 멀어지면(예: 깊은 실속 후) 보장은 약해진다.
그래서 우리는 두 가지로 대응한다. 하나는 게인 스케줄링이다(6장). 여러 운영점에서 각각 선형화하고
제어기를 만들어, 현재 조건에 맞는 것을 보간해 쓴다. 다른 하나는 INDI다(8장). 모델오차에 더 강건한
대안 내측 제어기로, 고기동 영역에서 선형화의 한계를 보완한다.

---

## 5.4 A와 B를 어떻게 구하나 — 유한차분

A와 B는 편미분 행렬이지만, 비행 모델 f가 시뮬레이터 안에 있으므로 해석적으로 미분하기 어렵다.
대신 수치 미분, 곧 유한차분으로 구한다. 발상은 단순하다. 평형점에서 한 상태를 아주 조금 흔들고
(다른 것은 고정), f가 얼마나 변하는지를 본다. 그 변화율이 A의 한 열이다.

중앙 차분을 쓴다. 한 성분 x_j를 더하고 뺀 두 경우의 f 차이를 2배의 변화량으로 나눈다.

```
A[:, j] = ( f(x0 + d·e_j, u0) − f(x0 − d·e_j, u0) ) / (2d)
B[:, j] = ( f(x0, u0 + d·e_j) − f(x0, u0 − d·e_j) ) / (2d)
```

여기서 e_j는 j번째 성분만 1인 단위벡터, d는 작은 변화량이다. 우리 구현(linearize.py)은 시뮬레이터를
짧게 굴려 f를 평가하고(조종면 작동기의 과도가 반영되도록 여러 물리 스텝), 모든 상태와 입력에 대해
이 차분을 돌려 A와 B 행렬을 채운다.

---

## 5.5 선형 모델이 맞는지 검증

수치로 구한 A가 옳은지 확인하는 좋은 방법은, A의 고유값이 비행기의 알려진 고전 운동 모드와 맞는지
보는 것이다. 항공기에는 잘 알려진 진동 모드가 있다. 종방향에는 느린 푸가이드(phugoid)와 빠른 단주기
(short period), 횡방향에는 더치롤(dutch roll), 롤 수렴, 나선 모드가 있다. 선형화가 제대로 되었다면
A의 고유값이 이 모드들의 주파수와 감쇠를 닮아야 한다. 우리 linearize.py는 이 고전 모드 검증을
포함한다.

고유값 검증은 6장과도 직접 이어진다. LQR 폐루프의 안정성은 A 빼기 B 곱하기 K의 고유값이 모두
좌반평면에 있는지로 판정하기 때문이다.

2. 평형점에서 1차 테일러 전개로 dx_dot = A·dx + B·du 를 유도하라. 버린 항의 크기는 무엇에 비례하나.
3. 리아푸노프 간접법은 선형화가 안정일 때 원래 비선형에 대해 무엇을 보장하는가. 그 보장의 범위는.
4. 중앙 차분으로 A의 한 열을 구하는 식을 적고, 왜 전진 차분 대신 중앙 차분을 쓰는지 설명하라.
5. 선형화가 잘 되었는지 고유값으로 검증하는 원리를 설명하라.
