# 7장. 종속 자동조종과 안정성 증명

## 학습 목표
이 장을 마치면 다음을 할 수 있다.
- 자동조종을 외측과 내측으로 나눈 종속(cascade) 구조의 이유를 설명한다.
- 고도, 방위, 속도 목표가 각각 어떤 외측 루프로 자세 목표가 되는지 안다.
- 협조선회 공식이 왜 phi = atan(psi_rate · V / g) 인지 유도한다.
- 목표값(Setpoint)이 어떻게 상태 목표 x*가 되고, 내측 LQR이 그것을 어떻게 실현하는지 안다.
- 종속 구조가 국소 점근 안정인 근거를 설명한다.
- "이건 그냥 PI 제어 아닌가"라는 반론에 답한다.

이 장은 6장의 LQR을 실제 자동조종으로 묶는다. LQR은 자세를 안정시키는 내측 엔진이고, 이 장은 그
위에 고도, 방위, 속도를 맞추는 외측을 얹어 완성한다.

---

## 7.1 왜 종속 구조인가

자동조종이 받는 목표는 고도, 방위, 속도다. 그런데 비행기를 직접 움직이는 것은 조종면이고, 조종면이
가장 먼저 바꾸는 것은 자세(피치와 뱅크)다. 고도는 자세의 결과로 천천히 바뀐다. 즉 시간 척도가 다르다.
자세는 빠르게, 고도와 방위는 느리게 변한다.

이 시간 척도 차이를 그대로 구조로 삼는다. 빠른 자세는 내측 루프가 안정시키고, 느린 고도·방위·속도는
외측 루프가 자세 목표를 만들어 그 안정된 자세를 명령한다. 이 두 겹 구조를 종속(cascade)이라 한다.

```
목표(고도,방위,속도)
   │  외측 (느림): 목표 → 자세 목표 theta*, phi*, throttle
   ▼
자세 목표 (theta*, phi*)
   │  내측 (빠름): LQR 이 자세를 목표로 안정화 → 조종면 u
   ▼
조종면 u → 비행기
```

장점은 둘이다. 첫째, 설계가 분리된다. 내측은 자세 안정만, 외측은 목표 추종만 책임진다. 둘째, 안정성
논증이 쉬워진다(7.5). 빠른 내측이 먼저 안정되면, 외측은 안정된 내측을 거의 즉각 반응하는 부품으로
보고 설계할 수 있다.

---

## 7.2 외측 루프 — 목표를 자세 목표로

외측은 세 개의 단순 루프다. 코드는 autopilot.py에 있다.

고도 루프(PI). 고도 오차를 비례-적분(PI)으로 받아 피치 자세 목표 theta*를 만든다. 너무 낮으면
기수를 들고(상승), 높으면 내린다. 적분 항이 정상상태 오차를 없앤다.

```
theta* = −( KP_H · (h − h*) + KI_H · ∫(h − h*) )   (포화 ±15도)
```

속도 루프(PI). 속도 오차를 PI로 받아 스로틀을 조정한다. 평형 스로틀(trim 값)을 기준으로 더하거나
뺀다.

```
throttle = throttle_trim − ( KP_V · (V − V*) + KI_V · ∫(V − V*) )
```

방위 루프(협조선회 P). 방위는 조금 다르다. 비행기는 방향을 바꾸려면 기울여야(뱅크) 한다. 그래서
방위 오차를 뱅크각 목표 phi*로 바꾼다. 이때 쓰는 것이 협조선회 공식이다(7.3).

```
psi_rate = KP_PSI · (psi − psi*)        (선회율 포화: 최대 약 20도/초)
phi* = atan( psi_rate · V / g )         (뱅크각 포화: 최대 약 78도)
```

세 외측 루프의 출력은 theta*, phi*, throttle 이다. theta*와 phi*가 내측 LQR의 자세 목표가 된다.

## 7.3 협조선회 공식 유도

수평면에서 일정 고도로 선회하는 비행기를 보자. 선회는 구심력을 필요로 하고, 그 구심력은 기울인
양력의 수평 성분에서 나온다. 양력을 L, 무게를 W = m·g, 뱅크각을 phi라 하면, 고도를 유지하려면
양력의 수직 성분이 무게와 같아야 한다.

```
그림 7.2  협조선회 힘 평형 (뒤에서 본 단면)

        L (양력, 날개에 수직)
         ╲
          ╲  phi (뱅크각)
           ╲ │
   L·sin φ  ╲│         L·cos φ = m·g      (수직: 무게와 균형)
   ◄─────────●         L·sin φ = m·V·ψ̇   (수평: 선회 구심력)
   (구심력)   │
             │ W = m·g (무게, 아래로)
             ▼
   기울인 양력의 수평 성분이 선회를 만든다.
```

```
L · cos(phi) = m · g            (수직 균형)
L · sin(phi) = m · V · psi_rate (수평 구심력)
```

두 식을 나누면 양력이 소거되고 다음이 남는다.

```
tan(phi) = V · psi_rate / g
phi = atan( V · psi_rate / g )
```

즉 원하는 선회율 psi_rate와 현재 속도 V가 정해지면, 필요한 뱅크각이 정확히 결정된다. 이것이 외측
방위 루프가 비례 게인으로 선회율을 정하고 이 공식으로 뱅크 목표를 내는 이유다. 비례만으로도 정확한
뱅크각이 나오고 오버슈트가 적다.

이 장의 협조선회는 3장에서 본 선회전(one-circle, two-circle)을 실제로 비행기에 시키는 저수준
수단이다. 9장의 유도가 "어느 방향으로 얼마나 돌아라"를 정하면, 여기 외측 루프가 그것을 뱅크각으로
번역하고, 내측 LQR이 그 뱅크를 만든다.

## 7.4 내측 루프 — 목표 자세를 상태 목표로

내측 LQR은 6장에서 설계했다. 외측이 준 theta*와 phi*를 자세 목표로 받는다. 방법은 단순하다. 현재
상태 x를 복사해 자세 두 성분만 목표로 바꾼 상태 목표 x*를 만든다.

```
x* = 현재 x 에서 theta 자리를 theta*, phi 자리를 phi* 로 교체한 것
u = u0 − K · (x − x*)
```

나머지 상태(속도, 받음각, 각속도 등)는 현재값을 목표로 두어 오차가 0이 되게 한다. 따라서 LQR은
오직 자세 오차(theta − theta*, phi − phi*)를 0으로 만드는 데 집중한다. 게인 K는 현재 운영점에 맞게
보간된 것을 쓴다(6장 게인 스케줄). 스로틀은 외측 속도 루프 값으로 덮어쓴다.

전체 한 tick의 흐름은 다음과 같다.

```
Setpoint(psi*, h*, V*)
   ├─ 고도 PI      → theta*
   ├─ 방위 P+협조  → phi*
   └─ 속도 PI      → throttle
        │
        ▼  x* = x with (theta←theta*, phi←phi*)
   내측 LQR: u = u0 − K(x − x*)   →   u = (throttle, elevator, aileron, rudder)
```

## 7.5 안정성 — 종속 구조가 국소 안정인 근거

종속 자동조종의 안정성은 두 단계로 논증된다.

내측. 6장에서 LQR 폐루프는 A 빼기 B 곱하기 K의 고유값이 모두 좌반평면에 있어 안정이다. 따라서
자세 오차는 빠르게 0으로 수렴한다.

외측. 내측이 외측보다 훨씬 빠르게 안정되면, 외측의 시간 척도에서 보면 자세는 명령한 목표에 거의
즉시 도달한 부품처럼 보인다. 이 시간 척도 분리(특이섭동, singular perturbation 관점)에서 외측 PI/P
루프는 안정된 내측 위에서 단순한 1차 추종으로 동작하며, 적절한 게인에서 안정하다.

합치면, 전체 폐루프를 평형점에서 선형화한 시스템이 Hurwitz가 되도록 게인을 잡을 수 있고, 그러면
5장의 리아푸노프 간접법에 의해 원래 비선형 자동조종도 평형점 근처에서 국소 점근 안정이다. 정직하게,
이 보장은 국소적이며 포화(뱅크·선회율 한계)가 걸리면 선형 논증을 벗어난다. 큰 기동에서의 거동은
게인 스케줄과 INDI(8장), 그리고 실측 검증(16장)으로 보완한다.

## 7.6 "이건 그냥 PI 제어 아닌가"

외측이 PI이고 내측이 게인 곱이니, 전체가 그저 PI 제어처럼 보일 수 있다. 답은 내측에 있다.

비행기의 자세는 단일 입출력이 아니라 여러 입력과 여러 출력이 서로 얽힌 다입력다출력(MIMO)
시스템이다. 엘리베이터는 피치만이 아니라 속도와 받음각에도 영향을 주고, 에일러론과 러더는 롤과
요가 커플링되어 있다. 단순한 채널별 PI는 이 커플링을 다루지 못해, 한 축을 잡으면 다른 축이 흔들린다.

LQR은 다르다. 모델(선형화 A, B)을 알고, 비용함수를 최소화하는 최적 게인 K를 푼다. 그 K는 커플링을
고려해 모든 채널을 동시에 조율한다. 게다가 K는 수치로 명시되고 폐루프 고유값으로 안정성이 증명되며,
운영점마다 다시 풀 수 있다(게인 스케줄). 즉 외형은 "오차에 게인을 곱한다"로 같아 보여도, 그 게인이
어디서 왔는가가 다르다. 임의로 손튜닝한 PI가 아니라, 모델 기반 최적해이고 증명 가능한 안정성을
가진다. 이것이 LQR을 쓰는 이유다.

## 연습문제
1. 종속 구조에서 내측과 외측은 각각 무엇을 책임지며, 둘을 나눈 근거(시간 척도)는 무엇인가.
2. 협조선회 공식 phi = atan(V·psi_rate/g) 를 수직 균형과 수평 구심력에서 유도하라.
3. 내측 LQR의 상태 목표 x* 는 현재 상태에서 무엇만 바꾼 것인가. 나머지 성분의 목표를 현재값으로
   두는 이유는.
4. 종속 자동조종이 국소 점근 안정이라는 논증을 내측과 외측 두 단계로 설명하라.
5. 단순 채널별 PI가 비행기 자세 제어에서 겪는 문제는 무엇이며, LQR은 그것을 어떻게 푸는가.
