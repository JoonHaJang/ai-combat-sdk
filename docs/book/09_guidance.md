# 9장. 유도 — 전술을 목표값으로

## 학습 목표
이 장을 마치면 다음을 할 수 있다.
- 유도(guidance)가 의사결정과 제어 사이에서 무엇을 하는지 설명한다.
- 전술(Tactic)이 어떻게 목표값 Setpoint(방위, 고도, 속도)가 되는지 안다.
- 세 추격 곡선(lead, pure, lag)을 기하로 구현하는 방법을 안다.
- 선행 추격을 요격 기하(intercept)로 푸는 이유와 방법을 안다.
- 사격 추적(GUN_TRACK)이 비례항법(PN)으로 어떻게 동작하는지 안다.
- 수직 기동(요요)과 선회전(one/two-circle) 명령이 어떻게 목표값으로 표현되는지 안다.

이 장은 4부의 핵심이다. 5부의 의사결정이 "어떤 전술"을 고르고, 3부의 제어가 "목표대로 비행"한다면,
유도는 그 사이에서 전술을 구체적 목표값으로 번역한다.

---

## 9.1 유도란 무엇인가

전술(Tactic)은 추상적이다. GUN_TRACK이나 HIGH_YOYO 같은 이름일 뿐, 비행기는 이름으로 날지
않는다. 제어(7장)는 구체적 목표값, 곧 향할 방위 psi*, 유지할 고도 h*, 낼 속도 V*를 받아야 움직인다.
유도는 이 둘을 잇는다.

```
전술(Tactic)  ──►  [ 유도 guidance ]  ──►  Setpoint(psi*, h*, V*)  ──►  제어(7장)
```

코드는 control/guidance.py의 GuidanceLayer다. 입력은 전술과 관측(거리, 각도, 적 위치·속도 등),
출력은 Setpoint 하나다. 내부는 전술마다 다른 기하 계산을 부른다(9.8의 디스패치 표).

---

## 9.2 Setpoint와 단위

Setpoint는 세 숫자다.

```
Setpoint = ( psi_star_deg, h_star_ft, v_star_kts )
            목표 방위(도)   목표 고도(ft)  목표 속도(kts)
```

표기법 장의 규약대로 외부 단위(도, 피트, 노트)를 쓴다. 모든 Setpoint는 안전 범위로 클램프된다.
방위는 0에서 360도로 정규화하고, 고도와 속도는 비행 가능 범위 안으로 자른다. 이 클램프가 유도가
물리적으로 무리한 목표를 내지 않도록 막는다.

---

## 9.3 추격 곡선의 구현

3장에서 추격을 lead, pure, lag로 나눴다. 유도는 이를 방위 목표 psi*로 구현한다.

순수 추격(pure pursuit). 기수를 적에게 정확히 댄다. psi*를 적의 현재 방위로 둔다. 가장 단순하다.

지연 추격(lag pursuit). 기수를 적의 뒤쪽에 둔다. psi*를 적 방위에서 적 진행방향의 반대쪽으로 조금
물린다. 접근을 늦추고 오버슈트를 막는다.

선행 추격(lead pursuit). 기수를 적의 미래 위치에 둔다. 단순히 "각에 비례해 앞을 본다"로 하면 과도하게
틀어 실패한다(계측). 그래서 표준 요격 기하로 푼다. 적의 현재 위치 p와 속도 v가 주어졌을 때, 내가
지금 속도로 직진하면 만나는 시각 tau를 구한다. 이는 거리·속도에 대한 2차 방정식이며, 양의 해가
요격 시각이다. 그 시각의 적 위치 p + tau·v 를 겨누면 그것이 선행 조준점이다.

```
조준점 = p + tau · v        (tau = 요격 시각, 2차 방정식의 양의 해)
psi*   = atan2(조준점 동쪽성분, 조준점 북쪽성분)
```

이 방법은 미사일·요격 유도의 표준(Zarchan)이며, 적이 도망(extend)할 때도 각과 거리를 함께 닫는다.

지연 변위 롤(lag displacement roll). 선행에서 순수 또는 지연으로 옮겨 꼬리 기준 각을 줄이는 기동
(3장)으로, 유도에서는 일시적으로 lag 쪽 방위 목표를 주어 구현한다.

## 9.4 사격 추적 — 비례항법(PN)

근접 사격을 마무리하는 GUN_TRACK은 비례항법(PN, Proportional Navigation)으로 구현한다. PN의
핵심 통찰은 이렇다. 내가 적과 충돌(요격) 경로에 있으면, 시선(LOS, line of sight)의 방향이 회전하지
않는다. 시선이 돌면 그 회전을 없애는 쪽으로 기수를 틀면 충돌 경로로 수렴한다.

그래서 GUN_TRACK은 시선 각속도(LOS rate)를 재고, 그 비례배만큼 방위 목표를 보정해 적의 선회를
앞당겨 겨눈다. 결과적으로 적이 돌아도 기수가 그 앞을 따라가 ATA가 12도 안으로 수렴하고, 무장 사용
구역(2장)에 머물러 피해를 만든다. 이는 미사일 유도의 고전 기법을 기총 추적에 적용한 것이다
(Zarchan, Palumbo).

```
그림 9.2  비례항법 — 시선 각속도를 0으로

  적 t1 ●╌╌╌╌╌╌► 적 t2          시선(LOS): 나에서 적을 잇는 선
        ╲          ╲             적이 옆으로 흐르면 LOS가 돌아간다(각속도 발생)
   LOS1   ╲    LOS2  ╲           순수 추격: 기수를 적에 둠 → LOS 계속 돌아 뒤처짐
            ╲          ╲         비례항법: 방위 목표를 LOS 각속도의 N배 앞당김
             ╲          ╲          psi* 보정 = N · (LOS 각속도)
              [나]                 → LOS 각속도가 0으로 수렴 = 적 앞을 선도해 겨눔
```

## 9.5 수직 기동 — 요요와 수직 추격

3장의 수직 기동을 유도는 고도 목표 h*와 속도 목표 V*의 조합으로 표현한다.

상부 요요(high yo-yo). 접근이 과해 오버슈트가 보일 때, 고도 목표를 올려 속도를 고도로 바꾼다. 접근과
선회율이 줄며 적 6시로 재정렬할 여유가 생긴다.

하부 요요(low yo-yo). 고도 목표를 잠시 낮춰 선회율을 끌어올리고 거리를 좁힌다. 상부 요요보다 약한
미세 조정이다.

수직 추격(vertical pursuit). 적이 멀리서 수직으로 빠질 때, 고도 목표를 적 고도로 둔다. 수평 추격이
놓치는 수직 성분을 따라가 적의 줌(zoom)에 붙는다.

```
그림 9.3  상부 요요 — 수직면 단면 (접근 과다 해소)

  고도
   ▲          ___                상부 요요: h*를 올림
   │        ╱   ╲                 1) 기수 올려 상승 → 속도가 고도로 바뀜
   │      ╱      ╲___             2) 접근속도·선회율 감소(오버슈트 회피)
   │    ╱  나         ╲           3) 위에서 내려보며 적 6시로 재정렬
   │ ──┘               ╲──        적 ●───────────► (수평 진행)
   └─────────────────────────► 거리
        속도→고도        고도→속도(강하 재가속)
```

## 9.6 선회전과 이탈 명령

one-circle. 적을 향해 같은 방향으로 강하게 도는 반경 싸움을 명령한다. 방위 목표를 적 쪽으로 강하게
틀고 코대코 기하를 만든다.

two-circle. 분리를 둔 뒤 코너 속도로 도는 선회율 싸움을 명령한다. 속도 목표를 코너 속도 부근으로
두어 선회율을 극대화한다.

break turn. 방어 시 공격자 진행방향으로 급선회하도록 방위 목표를 크게 틀어 오버슈트를 강요한다.

extension. 직선으로 가속해 거리를 벌리는 이탈. 방위 목표를 적 반대쪽으로 두고 속도 목표를 최대로
한다.

scissors. 연속 반전으로 상대 전진을 늦추는 기동으로, 방위 목표를 번갈아 반전시켜 구현한다.

---

## 9.7 적응 — ADAPTIVE 블렌딩

정면 매치에서 우리 정책이 거는 ADAPTIVE(11장)는 한 전술에 고정되지 않고 여러 기동을 연속으로
섞는다. 유도에서는 상황 변수(거리, 각, closure)에 따라 추격과 선회 목표를 매끄럽게 혼합(블렌딩)해
하나의 Setpoint로 낸다. 시그모이드 가중으로 급격한 전환 없이 섞어, 정면 전개에서 일관된 압박을
유지한다.

---

## 9.8 전체 디스패치

GuidanceLayer는 전술마다 위 기하 중 하나를 부른다. 요약하면 다음과 같다.

| 전술 | 유도가 만드는 목표 |
|---|---|
| PURE_PURSUIT | 적 현재 방위로 psi* |
| LAG_PURSUIT | 적 뒤쪽으로 물린 psi* |
| LEAD_PURSUIT | 요격 조준점으로 psi* (2차 해) |
| LAG_DISPLACEMENT_ROLL | 일시 lag 방위 |
| GUN_TRACK | LOS rate 기반 PN 보정 psi* |
| HIGH_YOYO / LOW_YOYO | 고도 목표 상향 / 하향 |
| VERTICAL_PURSUIT | 고도 목표 = 적 고도 |
| ONE_CIRCLE / TWO_CIRCLE | 코대코 강선회 / 코너속도 선회율 |
| BREAK_TURN | 공격자 진행방향 급선회 |
| EXTENSION | 적 반대 방위 + 최대 속도 |
| SCISSORS | 번갈아 반전 |
| ADAPTIVE | 상황 가중 블렌딩 |
| CLIMB | 안전 상승 목표 |

이 표가 3장의 전술 카탈로그와 7장의 자동조종을 잇는 다리다. 의사결정이 전술을 고르면(11장), 이
표가 목표값을 만들고, 7장의 종속 자동조종이 그 목표를 실제 비행으로 바꾼다.

## 연습문제
1. 유도가 의사결정과 제어 사이에서 하는 역할을 한 문장으로 적어라. 입력과 출력은 무엇인가.
2. 선행 추격을 "각에 비례한 lead"가 아니라 요격 기하로 푸는 이유는 무엇인가. tau는 무엇인가.
3. 비례항법의 핵심 통찰(충돌 경로에서 LOS가 회전하지 않는다)을 설명하고, GUN_TRACK이 이를 어떻게
   쓰는지 적어라.
4. 상부 요요와 수직 추격을 각각 고도 목표 h*로 어떻게 표현하는가.
5. one-circle와 two-circle 명령에서 속도 목표 V*를 다르게 두는 이유는 무엇인가.
