# Vendored JSBSim F-16 데이터

new_match_engine 의 `plant.py` 가 쓰는 F-16 6-DOF 비행데이터(aircraft/f16 + engine + systems).
- **출처**: JSBSim 표준 F-16A 모델 (General Dynamics F-16A). JSBSim 프로젝트 공개 항공기 데이터.
- **라이선스**: 동봉 `COPYING` 참조 (JSBSim 데이터 라이선스).
- **용도**: standalone JSBSim plant 의 결정론 F-16 (native FLCS 포함). 재현성을 위해 번들.
